# PARKING — ไอเดียที่ยังไม่ทำ (ห้าม implement จนกว่าจะรีวิวหลัง Phase 10)

> กติกา §0 ข้อ 4: ไอเดียใหม่ทุกอย่างที่ไม่อยู่ในแผน 10 เฟส ให้จดที่นี่เท่านั้น

## Gameplay
- ทิศที่หันของฮีโร่จำกัดมุมโจมตีจริง (แบบ Arknights) — ทำเป็น modifier ของโหมด Hard/Hell แทนที่จะเป็นกติกาพื้นฐาน
- กับดัก/สิ่งก่อสร้างวางได้ (Merchant สาย Alchemist)
- ช่องพิเศษบนแผนที่: บ่อพิษ, แท่นบูสต์, เนินที่เพิ่มระยะยิง
- ศัตรูที่ทำลายฮีโร่ที่วางไว้ (destroyer) และศัตรูที่แยกร่างเมื่อตาย
- โหมด Roguelite แบบ Arknights IS

## Meta
- Arena แบบ async ที่ผู้เล่นออกแบบเวฟบุกเอง (นวัตกรรมที่ยังไม่มีใครทำ — blueprint §9.6)
- กิลด์ + บอสกิลด์, Co-op 2 คน
- ระบบสะสมแต้ม/สมาชิก, รีวิวสินค้าในร้านค้า
- แจ้งเตือนสินค้ากลับมามีสต๊อก (ยืมแนวคิดจากอีคอมเมิร์ซ)

## Tech
- InstancedMesh สำหรับพื้นทั้งกระดาน (ถ้า fps บนมือถือไม่ถึงเป้า)
- Replay viewer: เก็บ seed + command log แล้วเล่นย้อนหลัง (โครงพร้อมแล้วใน `Command[]`)
- Level editor ในเบราว์เซอร์สำหรับวาด `Stage.tiles`
- Web Worker รัน sim แยกเธรดจาก render
- Sprite atlas แบบ SDF/vector สำหรับจอความละเอียดสูงมาก
