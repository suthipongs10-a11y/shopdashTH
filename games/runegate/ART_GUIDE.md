# ART_GUIDE — สเปกอาร์ตของ RUNEGATE (Phase 3)

> เอกสารนี้คือ "สัญญา" ระหว่างคนวาดกับเกม — วาดตามนี้แล้ววางไฟล์ให้ถูกที่ เกมจะใช้ทันทีโดยไม่ต้องแก้โค้ด

---

## 1. สเปกเฟรม (ห้ามเปลี่ยน)

| หัวข้อ | ค่า |
|---|---|
| ขนาดเฟรม | **96 × 128 px** (กว้าง × สูง) |
| พื้นหลัง | โปร่งใส (PNG-32) |
| เท้าตัวละคร | อยู่ที่ **y = 120** (เหลือขอบล่าง 8 px ไว้ให้เงา) |
| จุดกึ่งกลางตัว | x = 48 |
| ความสูงตัวละคร | ~46–66 px สำหรับตัวขนาดปกติ · บอสใหญ่ได้ถึง ~100 px |
| ทิศที่ต้องวาด | **5 ทิศ** — เกมพลิกเอาเองเป็น 8 ทิศ |

### ทิศ (แถวใน atlas)
| แถว | ทิศ | หมายเหตุ |
|---|---|---|
| 0 | หันหน้าเข้าหากล้อง | เห็นหน้าเต็ม |
| 1 | หน้าเฉียง | เห็นหน้า 3/4 |
| 2 | ด้านข้าง | เห็นตาข้างเดียว |
| 3 | หลังเฉียง | ไม่เห็นหน้า |
| 4 | หันหลัง | ไม่เห็นหน้า |

> ทิศซ้ายทั้งหมดเกมพลิกจากทิศขวาเอง (สูตรเดียวกับ Ragnarok Online — ประหยัดงานวาด 37%)
> **ผลที่ตามมา:** ห้ามใส่รายละเอียดที่ไม่สมมาตรซ้าย-ขวา เช่น รอยแผลข้างเดียว หรือตัวอักษรบนเสื้อ

### ท่าและจำนวนเฟรม (ต่อ 1 ทิศ)
| ท่า | เฟรม | fps | วนซ้ำ | ใช้ตอน |
|---|---|---|---|---|
| `idle` | 2 | 3 | ✔ | ยืนเฉย |
| `walk` | 4 | 8 | ✔ | เดิน (ศัตรูใช้เยอะสุด) |
| `attack` | 3 | 11 | ✘ | โจมตี |
| `death` | 3 | 7 | ✘ | ตาย (เกมค่อยๆ จางให้เอง) |

รวม **12 เฟรม × 5 ทิศ = 60 ไฟล์ต่อตัวละคร 1 ตัว**

## 2. ชื่อไฟล์และโฟลเดอร์

```
art/src/{id}/{ท่า}_{ทิศ}_{เฟรม}.png
```
`{id}` ต้องตรงกับ id ในไฟล์คอนเทนต์เป๊ะ (ดูรายชื่อทั้งหมดด้วย `npm run art-status`)

```
art/src/warden_kael/idle_0_0.png
art/src/warden_kael/idle_0_1.png
art/src/warden_kael/walk_2_3.png
art/src/ghoul/death_4_2.png
```

แพ็คด้วย:
```bash
npm run pack-sprites          # art/src → packages/client/public/art
npm run art-status            # ดูว่าตัวไหนมีอาร์ตจริงแล้ว ตัวไหนยังใช้ placeholder
```

Packer จะตรวจให้เองว่าเฟรมครบไหมและขนาดถูกไหม — ถ้าไม่ครบจะบอกว่าขาดไฟล์ไหน

## 3. สไตล์ (ล็อคทั้งเกม)

**โลก:** แฟนตาซีสากล ประตูมิติหิน รูนเรืองแสง ทัพอสูร — โทนกลางคืน แสงคบไฟ

| หัวข้อ | กติกา |
|---|---|
| เส้นขอบ | เส้นขอบเข้ม `#181222` หนา 2 px รอบตัวละคร (ไม่ใช่สีดำสนิท) |
| แสง | แหล่งแสงหลักมาจาก **บนซ้าย** เสมอ · rim light เย็น `#7fd4e8` บางๆ ที่ขอบขวาบน |
| เงา | ไม่ต้องวาดเงาใต้ตัว — เกมวาดให้เอง |
| จำนวนสี | ≤ 12 สีต่อตัวละคร (รวมเส้นขอบ) — คุมให้เป็นชุดเดียวกันทั้งเกม |
| ความอิ่มสี | ตัวฝ่ายเราสีอิ่มกว่า ศัตรูหม่นกว่า บอสมีสีเน้น 1 สีที่ตัดขาดจากพื้นหลัง |
| อ่านง่าย | ดูที่ 64 px ต้องแยกออกทันทีว่าเป็นอะไร — เงาทึบของตัวละครต้องบอกชนิดได้โดยไม่ต้องดูรายละเอียด |

**พาเลตต์อ้างอิงของเกม** (ใช้เป็นตัวตั้ง ไม่ใช่ข้อบังคับทุกสี)
`#0a0e15` พื้นหลังกลางคืน · `#7fd4e8` รูน/ของฝ่ายเรา · `#f0803c` ไฟ/อันตราย · `#c9a86a` ทองเหลืองเก่า · `#e6edf3` ตัวหนังสือ

## 3.5 Prompt สำเร็จรูปสำหรับ AI วาดรูป

```bash
npm run art-prompts     # สร้าง prompt ครบทั้ง 63 ตัวลง art/prompts/
```

ได้ prompt ภาษาอังกฤษพร้อมใช้ **7 ชุดต่อตัวละคร** (ภาพต้นแบบ → เทิร์นอะราวด์ 5 ทิศ → สไปรท์ชีต 4 ท่า × 5 ทิศ → เฟรมเดี่ยวไว้ซ่อม)
ทุก prompt ฝังสเปกในเอกสารนี้ไว้แล้ว: เส้นขอบ `#181222` · rim light `#7fd4e8` · ≤12 สี · ห้ามมีเงาใต้ตัว · ทุกภาพหันขวา
พร้อมพาเลตต์ hex และความสูงเป็น px ของตัวละครแต่ละตัวที่ดึงมาจากคอนเทนต์จริง

- เริ่มอ่านที่ `art/prompts/README.md` · เช็คลิสต์ทุกตัวที่ `art/prompts/INDEX.md`
- คำบรรยายตัวละคร (silhouette/details/ท่าโจมตี/ท่าตาย) อยู่ใน `packages/data/content/art_briefs.json`
- เพิ่มมอนใหม่แล้วลืมเขียนคำบรรยาย → `npm run validate` ฟ้องให้

## 4. ลำดับงานที่แนะนำ

1. **ล็อก style reference ก่อน 1 ชุด** — วาด/gen ตัวละคร 1 ตัวให้จบทุกท่าทุกทิศ ใช้เป็นไม้บรรทัดของทั้งเกม
2. Gen ภาพต้นแบบ (AI ก็ได้) → ทำ turnaround 5 ทิศ → แตกเป็นเฟรม
3. เก็บงานใน Aseprite: คุมเส้นขอบ เงา และพาเลตต์ให้เป็นชุดเดียวกัน (งานมือราว 20–30% ของเวลา)
4. `npm run pack-sprites` แล้วเปิดเกมดูจริง — เกมจะสลับจาก placeholder เป็นอาร์ตจริงให้เองทันที

**ลำดับความสำคัญ:** ฮีโร่ ★5 ก่อน → มอนสเตอร์ที่โผล่บ่อยที่สุด (`ghoul`, `skeleton_soldier`, `restless_shade`) → บอส MVP → ที่เหลือ

## 5. ทำไมต้องเป็น placeholder ก่อน

โค้ดฝั่ง render ไม่รู้จักความต่างระหว่าง placeholder กับอาร์ตจริงเลย — ทั้งคู่คือ atlas รูปแบบเดียวกัน
เกมจึงเล่นได้เต็มรูปแบบตั้งแต่ยังไม่มีอาร์ต และอาร์ตที่วาดเสร็จทีละตัวก็ทยอยเข้าเกมได้โดยไม่ต้องรอครบ
