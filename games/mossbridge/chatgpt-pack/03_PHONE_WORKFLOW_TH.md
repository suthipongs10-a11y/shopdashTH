# สั่งภาพจากมือถือ: Claude เขียน prompt → ChatGPT วาด → ส่งกลับให้ Claude

ใช้เมื่อคุยกับ Claude บนมือถือหรือเว็บ (Claude สั่ง ChatGPT เองไม่ได้ เพราะไม่มีเบราว์เซอร์)

## 1. ขอ prompt จาก Claude

บอก Claude ว่าอยากได้ภาพอะไร (หรือ "ทำ backlog ข้อถัดไป") แล้ว Claude จะ:
- เขียน prompt ลงไฟล์ `chatgpt-pack/prompts/Pxx_*.txt` และ commit ไว้
- ส่ง prompt ในแชท **1 กล่องโค้ดต่อ 1 ภาพ** พร้อมชื่อไฟล์ `SAVE AS:` ให้กดคัดลอกได้เลย

## 2. ให้ ChatGPT วาด (แอป ChatGPT บนมือถือ บัญชี Plus)

- ใช้แชทเดิมที่มีภาพต้นแบบอยู่แล้ว (ชื่อแชท "Acknowledge Readiness" มี REF_01–08, P01–P10 อยู่ในนั้น)
  ถ้าเริ่มแชทใหม่: แนบรูปใน `chatgpt-pack/refs/` + ภาพที่ prompt อ้างถึง (เช่น P01, P03) แล้ววางข้อความ `01_START_HERE_for_ChatGPT.md` ก่อน
- วาง prompt ทีละกล่อง 1 ข้อความ = 1 ภาพ
- ถ้า ChatGPT ถามว่า "ภาพไหนดีกว่า" ให้เลือกภาพที่ตรงกติกา (ตารางช่องเท่ากัน ขนาดตัวเท่ากัน พื้นหลังม่วงเรียบ) หรือส่งทั้งสองภาพให้ Claude เลือก
- ถ้าต้องการให้ท่า/ขนาดเหมือนภาพเดิมเป๊ะ ใช้ปุ่ม **Edit** บนภาพเดิมแล้วพิมพ์สิ่งที่จะแก้ (Claude จะบอกเมื่อควรใช้วิธีนี้)
- กดค้างที่ภาพ → บันทึกภาพ (ได้ PNG ขนาดเต็ม)

## 3. ส่งภาพกลับให้ Claude

**วิธีหลัก (Claude เอาไปใช้ต่อได้ทันที):** อัปโหลดเข้า GitHub
1. เปิด github.com/suthipongs10-a11y/shopdashTH ในเบราว์เซอร์มือถือ → เลือก branch ที่ Claude บอก
2. เข้าโฟลเดอร์ `games/mossbridge/art/inbox/` → **Add file → Upload files** → เลือกภาพ
3. เปลี่ยนชื่อไฟล์ให้ตรง `SAVE AS:` ก่อนอัปโหลด (หรือบอกใน commit message ว่าภาพไหนเป็นภาพอะไร)
4. กด Commit แล้วบอก Claude ว่า "อัปโหลดแล้ว"

**วิธีเร็ว (ให้ Claude ดูก่อนว่าผ่านไหม):** แนบภาพในแชท Claude ได้เลย Claude จะตรวจและบอกว่าผ่าน/ต้องแก้
แต่ถ้าจะนำภาพไปใช้ในเกม ยังต้องอัปโหลดเข้า GitHub ตามวิธีหลัก

## 4. Claude ทำอะไรต่อ

- ตรวจภาพตามกติกา (พื้นหลัง, มุมกล้อง, ขนาด, หน้าตาตรง P01 ฯลฯ) → ถ้าไม่ผ่าน ส่งประโยคแก้ให้ไปวางต่อในแชท ChatGPT เดิม
- ภาพที่ผ่าน: ย้ายจาก `art/inbox/` ไป `art/raw/` → รันเครื่องมือล้างภาพ/สร้าง asset → อัปเดตเดโม → commit + push
