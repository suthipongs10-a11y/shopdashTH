# ชุดคำสั่งสร้างภาพ Mossbridge สำหรับ ChatGPT

> **อัปเดต 2026-11-06:** P01–P10 สั่งครบแล้ว (ภาพอยู่ `art/raw/`) · ภาพชุดใหม่ (P11 ขึ้นไป) Claude จะเขียน prompt ให้ทีละชุด
> ขั้นตอนบนมือถือ (คัดลอก prompt → ChatGPT → อัปโหลดภาพกลับ) อยู่ใน **`03_PHONE_WORKFLOW_TH.md`**
> ข้อ 4 ด้านล่าง (ประโยคแก้ภาพ) ยังใช้ได้กับทุกชุด

ชุดนี้คือรายการภาพที่ต้องใช้ทำเดโมต่อ เรียงตามความสำคัญ ทำตามข้อ 1 → 5 ได้เลย

## 1. เตรียมแชท

1. เปิดแชทใหม่ใน ChatGPT (ใช้โมเดลที่สร้างภาพได้)
2. **ลากรูปทั้งหมดในโฟลเดอร์ `refs/` ใส่แชทโดยตรง** (8 รูป)
   ต้องแนบรูปเองด้วย เพราะ ChatGPT ใช้รูปที่อยู่ในไฟล์ zip เป็นต้นแบบตอนวาดไม่ได้
3. คัดลอกข้อความทั้งหมดใน `01_START_HERE_for_ChatGPT.md` วางเป็นข้อความแรก แล้วส่ง
4. ChatGPT จะตอบว่าเข้าใจกติกาแล้ว

> ถ้าแนบ zip ทั้งไฟล์ไปด้วย ChatGPT จะอ่านคำสั่งในนั้นเองได้ แต่ยังต้องลากรูปใน `refs/` ใส่แชทอยู่ดี

## 2. สั่งทีละภาพ

- เปิดไฟล์ในโฟลเดอร์ `prompts/` ตามลำดับเลข (P01, P02, …)
- ในไฟล์หนึ่งอาจมีหลายภาพ คั่นด้วยเส้น `=====` **ให้ส่งทีละช่อง** (1 ข้อความ = 1 ภาพ)
- คัดลอกเฉพาะส่วนใต้หัวข้อ `PROMPT:` ไปวาง
- ถ้าภาพผิดกติกา ใช้ประโยคแก้ภาพในตารางข้อ 4

## 3. บันทึกภาพแล้วส่งกลับมาให้ผม

ตั้งชื่อไฟล์ตามที่เขียนไว้ในบรรทัด `SAVE AS:` ของแต่ละช่อง (เช่น `P01_kaelrin_body_empty_hands.png`)
แล้วรวมเป็น zip ส่งกลับมาในแชทนี้ ไม่ต้องตัด ไม่ต้องลบพื้นหลัง ผมจัดการเอง

**สำคัญที่สุด (ทำแค่นี้ก่อนก็พอ):** P01, P02, P03 ได้ 3 ชุดนี้ผมจะเปลี่ยนตัวละครในเดโมเป็นแบบหัวแยกจากตัว ใส่หมวกได้ และอาวุธขอบสะอาด

## 4. ตรวจภาพก่อนเก็บ (ถ้าผิด ให้พิมพ์ประโยคขวามือต่อในแชทเดิม)

| ปัญหาที่เห็น | พิมพ์ต่อ |
|---|---|
| พื้นหลังไม่ใช่สีเดียวเรียบ | `Redo it with ONE flat solid background color exactly as specified, no gradient, no floor, no shadow.` |
| หน้าตา/ชุดไม่เหมือน Kaelrin ในรูป REF_03 | `The character must match REF_03 exactly: same face, teal spiky hair, teal armor with brass trim, scarf, belt pouch. Redo.` |
| มุมกล้องผิด | `Same design, but each cell must use exactly the camera angle shown in the matching view of REF_03.` |
| ขนาดในแต่ละช่องไม่เท่ากัน | `All cells must be the same scale, feet on the same baseline.` |
| ชิ้นติดกัน/ล้นช่อง | `Leave much more empty space; nothing may touch or cross the cell borders.` |
| มีประกาย แสงฟุ้ง ตัวอักษร | `Remove all glow, sparkles, text and decorations outside the object.` |
| ยังถืออาวุธอยู่ (P01) | `Hands must be EMPTY. No weapon, no tool. The right hand is a closed fist.` |
