# 03 — Sprite & Asset Spec (สเปคภาพสำหรับสั่ง ChatGPT และนำเข้าเกม)

> ตัวเลขทุกตัวในเอกสารนี้ตรงกับโค้ดใน `prototype/headgear-lab/index.html` ถ้าจะเปลี่ยน ให้แก้ทั้งสองที่พร้อมกัน
> หน่วยเป็นพิกเซลที่ **ความละเอียดต้นฉบับ @2x** (เกมแสดงผลที่ 0.5×)

---

## 1. ระบบพิกัด

- จุดกำเนิดตัวละคร = **จุดเท้าแตะพื้น (feet)** = (0, 0) แกน y ขึ้นเป็นลบ
- ทุกภาพที่ "วาดหันขวา" เป็นต้นฉบับ ทิศซ้ายได้จาก `scaleX = -1` รอบจุด feet
- จุดยึด (pivot) ของแต่ละชิ้นเขียนเป็นพิกัด **บนแคนวาสของชิ้นนั้น**

## 2. ทิศ (Directions)

| ระยะ | ทิศที่วาดจริง | ทิศที่กลับภาพ | ภาพต่อหมวก 1 ใบ |
|---|---|---|---|
| **MVP (ตอนนี้)** | `front` = SE, `back` = NE | SW ← SE, NW ← NE | **2 ภาพ** |
| อัปเกรด 8 ทิศ | S, SE, E, NE, N | SW ← SE, W ← E, NW ← NE | 5 ภาพ |

การเดิน 8 ทิศบนแผนที่ map เข้า sprite ที่ใกล้สุด: ขึ้น → `back`, ลง → `front`, ซ้าย/ขวา → คง view เดิมแล้วแค่กลับด้าน (ทำแล้วใน lab: ฟังก์ชัน `face()`)
ข้อมูลทิศเก็บเป็น `"front" | "back"` ตอนนี้ และเปลี่ยนเป็น `"s"|"se"|"e"|"ne"|"n"` ทีหลังได้โดยไม่ต้องรื้อ เพราะทุกตารางผูกกับชื่อ view

## 3. เลเยอร์ของตัวละครผู้เล่น (Paper-doll)

```
            ┌───────────── head_top  (หมวก)           ┐
            │ ┌─────────── head_mid  (แว่น)            │  แคนวาสหัว 256×256
            │ │ ┌───────── head_low  (หน้ากาก/ปาก)     │  pivot = คอ (128,200)
            │ │ │ ┌─────── hair_front ┐               │  ทุกชิ้นใช้แคนวาส+pivot เดียวกัน
            │ │ │ │ ┌───── face       ├ "head"        │
            │ │ │ │ │ ┌─── hair_back  ┘               ┘
            ▼ ▼ ▼ ▼ ▼ ▼
   neck ●  (hip + (0,-80))      ← หัวทั้งชุดยึดตรงนี้ และขยับตามลำตัวทุกเฟรม
   torso   pivot hip (100,150) บนแคนวาส 200×170, hip อยู่ที่ feet + (0,-52)
   arm_back / arm_front / weapon / shield   (ระยะถัดไป)
   leg_l / leg_r  แคนวาส 40×60 pivot บน-กลาง (20,0)
   shadow  (เกมวาดเอง)
   feet ●  (0,0)
```

### ลำดับการวาด (draw order) ต่อ view
| view | ลำดับ (ล่าง → บน) |
|---|---|
| front | shadow → garment_back → leg ×2 → arm_back → torso → head(hair_back, face, hair_front) → head_low → head_mid → head_top → arm_front → weapon → shield |
| back | shadow → weapon → shield → arm_front → leg ×2 → torso → arm_back → head → head_low → head_mid → head_top → garment |

ลำดับนี้เป็นข้อมูล (JSON) ไม่ใช่โค้ด ปรับต่อทิศได้ใน `drawOrder`
**ไอเท็มที่มองไม่เห็นจากด้านหลัง (แว่น หนวด) ให้ภาพ back เป็นภาพว่างได้** (lab ทำแล้ว: `drawGlasses` คืนค่าว่างเมื่อ view=back)

## 4. แคนวาสมาตรฐาน

| ชิ้น | แคนวาส | pivot | เนื้อภาพ |
|---|---|---|---|
| ตัวเต็ม (NPC/อ้างอิง) | 320×320 | feet (160,300) | สูง 256 (มนุษย์) |
| ลำตัว torso | 200×170 | hip (100,150) | ไหล่ถึงสะโพก, จุดคอที่ (100,70) |
| ขา 1 ข้าง | 40×60 | (20,0) ต้นขา | ยาว 52 ถึงพื้น |
| แขน 1 ข้าง (ระยะถัดไป) | 60×90 | ไหล่ (30,10) | มือที่ (30,80) = จุดถืออาวุธ |
| **แคนวาสหัว (ทุกชิ้นของหัว)** | **256×256** | **คอ (128,200)** | หัวโล้นเป็นวงรี center (130,140) rx 60 ry 56 → ยอดหัว y=84 |
| อาวุธ | 256×256 | ด้ามจับ (128,160) | ยาวไม่เกิน 220 |
| มอนสเตอร์ | 256 / 384 / 512 จัตุรัส | feet กลางล่าง (w/2, h−20) | ตามขนาด §02-3 |
| ไอคอนไอเท็ม | 96×96 | — | ขอบใส 4 px |
| พร็อพฉาก | ตามจริง (คูณ 32) | ฐานกลางล่าง | — |

## 5. ชิ้นหัว: หน้า + ผม

- `face/{skinTone}/{view}.png` — หัวโล้น หู ตา ปาก (ใช้ร่วมทุกทรงผม) ภายหลังเพิ่ม expression ได้ (`face/light/front_smile.png`)
- `hair/{styleId}/{mode}/{view}_back.png` และ `_front.png`
  - `mode` = `full` | `capped` (ดู §6) — ไม่ต้องมี `hidden` เพราะคือ "ไม่วาดผม"
  - `_back` = ส่วนผมหลังหัว (ผมยาว หางม้าตอนหันหน้า) วาดก่อน face
  - `_front` = หน้าม้า ยอดผม วาดหลัง face
- **ผมวาดเป็นโทนเทาอ่อน (light neutral gray) มีเงา** แล้วเกมย้อมสีด้วย tint แบบ multiply → ทรงเดียวได้ทุกสีผม
- แต่ละทรงผมกำหนด `crownY` ต่อ view = ยอดผมสูงกว่ายอดหัวโล้นกี่ px (ค่าลบ) เช่น ทรงชี้ฟู front −26
  หมวกโหมด `full` จะถูกยกขึ้นตาม `crownY` อัตโนมัติ จึงวางบนผมพอดีทุกทรง

## 6. Headgear (หัวใจของระบบ)

### 6.1 ช่องและการกินช่อง
| ช่อง | ตัวอย่าง | หมายเหตุ |
|---|---|---|
| `head_top` | หมวก มงกุฎ หูแมว หมวกเกราะ | ไอเท็มใหญ่ |
| `head_mid` | แว่น แว่นกันลม ผ้าปิดตา | ระดับตา (y ≈ 140–150) |
| `head_low` | หน้ากาก ผ้าปิดปาก หนวด ใบไม้คาบปาก | ระดับปาก (y ≈ 160–195) |

ไอเท็มกินหลายช่องได้ด้วย `occupies` เช่น หมวกเกราะเต็มหน้า `["head_top","head_mid"]` (ใส่แล้วถอดแว่นอัตโนมัติ)

### 6.2 กฎการวาดหมวก
1. วาดบน **แคนวาสหัว 256×256** โดยวางทับ "หัวโล้นแม่แบบ" (`art/samples` + lab ช่วยดู) — เส้นขอบล่างของปีกหมวกแม่มด/ไหมพรม อยู่ราว y = 100–120
2. พื้นหลังใส หรือ #FF00FF แล้วรัน `sprite_clean.py --fit none`
3. หมวกโหมด `capped` ต้องปิดยอดหัวลงมาถึงอย่างน้อย y = 100 (ใต้นั้นคือผม capped ที่โผล่ข้าง ๆ)
4. หมวกยาวเลยแคนวาสได้ ถ้าจำเป็นให้ใช้แคนวาส 384×384 โดยรักษาสัดส่วน pivot (192, 300) — เกม normalize ให้เอง
5. ภาพ `back` ต้องเป็นมุมหลังจริง (ไม่มีอัญมณีหน้า ไม่มีหน้าคน)

### 6.3 Metadata ไอเท็ม (รูปแบบเดียวกับที่ lab export)
```jsonc
{
  "id": "hat_witch",
  "slot": "head_top",
  "occupies": ["head_top"],
  "name_th": "หมวกแม่มดม่วง",
  "viewId": 1201,                 // เลขที่เซิร์ฟเวอร์ส่งให้ client แทนชื่อไฟล์ (เหมือน view id ของ RO)
  "hair": "capped",               // full | capped | hidden
  "layers": { "front": "headgear/hat_witch/front.png", "back": "headgear/hat_witch/back.png" },
  "fit": {                        // จูนใน Headgear Lab แล้ว Export JSON มาวางตรงนี้
    "front": { "dx": 0, "dy": 0, "s": 1 },
    "back":  { "dx": 0, "dy": 0, "s": 1 }
  },
  "dye": false,                   // ย้อมสีได้ไหม (ระยะถัดไป)
  "stats": { "def": 2, "int": 1 }
}
```

## 7. แอนิเมชัน (cutout rig — ทางเลือก B ใน 01-feasibility)

ภาพนิ่งชุดเดียว + keyframe ใน JSON (`anims/{animId}.json`: ต่อเฟรมบอก offset/rotation ของ torso, arm, leg, head)

| แอนิเมชัน | ระยะ | ความยาว | หมายเหตุ |
|---|---|---|---|
| idle | M1 | loop 1.6 s | หายใจ (torso scaleY 1.0↔1.012), หัวขยับ 1 px (ทำแล้ว) |
| walk | M1 | loop 0.7 s | ขาแกว่ง ±0.18 rad, ตัวเด้ง 7 px (ทำแล้ว) |
| attack_1h | M2 | 0.45 s | ต้องมีแขนแยก + อาวุธยึดมือ |
| cast | M3 | 0.8 s | ยกแขน + effect |
| hit / die / sit | M3 | — | — |

เพิ่มท่าได้โดย**ไม่ต้องสั่งภาพใหม่** หมวกตามหัวไปเองทุกท่า

## 8. NPC และมอนสเตอร์

- NPC ที่ไม่เปลี่ยนชุด: ใช้ "ตัวเต็ม" ภาพเดียวต่อ view ได้ (เช่น Bram, Minae ใน `art/samples`) + idle แบบหายใจ
- มอนสเตอร์เล็ก (สไลม์): 1 ภาพต่อ view + squash & stretch ด้วยโค้ด
- มอนสเตอร์ใหญ่/บอส (หมูป่ามอส): cutout = ลำตัว, หัว, ขา 4 ข้าง, หาง; effect เรืองแสงแยกชั้น (additive)

## 9. Effect, ไอคอน, UI

- Effect สกิล: sprite sheet ตามเฟรมได้ (เร็ว ความไม่สม่ำเสมอเล็กน้อยไม่เห็น) 6–12 เฟรม แคนวาส 256 หรือ 512, ใช้ blend แบบ additive
- ไอคอน: 96×96 พื้นใส มุมเฉียงสวยงาม ไม่มีกรอบ (เกมใส่กรอบตามความหายาก)
- UI: 9-slice กรอบไม้+ทองเหลือง (ระยะ M4)

## 10. โครงโฟลเดอร์ asset และการตั้งชื่อ

```
art/
  reference/                  ภาพอ้างอิงสไตล์ (ห้ามนำเข้าเกม)
  raw/{date}_{what}.png       ภาพดิบจาก ChatGPT (ไม่ต้อง commit ก็ได้)
  samples/                    ผลลัพธ์ตัวอย่างจาก sprite_clean.py
client/public/assets/
  body/{bodyId}/{view}/torso.png, leg.png, arm_front.png, arm_back.png
  face/{skin}/{view}.png
  hair/{styleId}/{full|capped}/{view}_front.png, {view}_back.png
  headgear/{itemId}/{view}.png
  weapon/{itemId}/{view}.png
  mob/{mobId}/{view}/{part}.png
  icon/{itemId}.png
  map/{mapId}/ground.webp, overlay.webp, map.json (Tiled)
```
ชื่อไฟล์ตัวเล็ก ขีดล่าง ภาษาอังกฤษ: `hat_witch`, `hair_spiky`, `mob_mossback`
