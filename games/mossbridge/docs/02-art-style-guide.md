# 02 — Art Style Guide: Mossbridge

## 1. เสาหลักของสไตล์ (Style Pillars)

1. **Cozy high-fantasy** อบอุ่น ปลอดภัย น่าอยู่ ไม่ใช่ dark fantasy เมืองไม้ หลังคาเทอร์ควอยซ์ ลำธาร ดอกไม้ ป่าเขียวสด
2. **Chibi hand-painted** ตัวละครหัวโต ลงสีแบบภาพวาดมือ (painterly) เงานุ่ม มีแสงขอบ (rim light) บาง ๆ ไม่ใช่ pixel art ไม่ใช่ 3D เงาวาว
3. **อ่านรูปทรงออกตั้งแต่ไกล** silhouette ชัด สีหลักของแต่ละตัวต่างกันชัด (ฮีโร่ = เทอร์ควอยซ์+ทองเหลือง, Minae = ม่วง, Bram = น้ำตาล-ส้ม)
4. **Golden hour** แสงอุ่นเหมือนบ่ายแก่ ๆ เงาโทนม่วงอมน้ำเงิน ไม่ใช่เงาดำ

## 2. มุมกล้องและโปรเจกชัน (สำคัญที่สุดสำหรับใช้ในเกม)

| สิ่งของ | มุม | กฎ |
|---|---|---|
| แผนที่/ฉาก | **Orthographic 3/4 top-down** (มองลงประมาณ 45°) | **ไม่มีจุดลับตา (no perspective)**: ของไกลกับใกล้ขนาดเท่ากัน เส้นแนวตั้งตั้งตรงทั้งภาพ |
| ตัวละคร/มอนสเตอร์ | 3/4 top-down มุมเดียวกับฉาก | วาด **SE (หน้า หันขวาล่าง)** กับ **NE (หลัง หันขวาบน)** ส่วน SW/NW ได้จากการกลับภาพ |
| ไอคอนไอเท็ม | มุมเอียงสวย ๆ ได้อิสระ | พื้นหลังใส ขอบเข้ม อ่านออกที่ 48 px |
| พอร์เทรต/แบนเนอร์ UI | อิสระ | ใช้สไตล์เดียวกับ concept |

> `02_Environment.png` มี perspective (หินปูถนนด้านหลังเล็กลง ตัวละครไกลเล็กลง) สวยในฐานะภาพโปรโมต
> แต่ทำแผนที่ไม่ได้ ตอนสั่งฉากใหม่ต้องใส่ "orthographic, no vanishing point, consistent scale" เสมอ

## 3. สัดส่วนตัวละคร

- สูงประมาณ **2.5 หัว** หัวกว้างกว่าไหล่เล็กน้อย ตาโต มือเท้าใหญ่
- สเกลมาตรฐาน: ตัวละครผู้ใหญ่สูง **256 px** ที่ความละเอียดต้นฉบับ (@2x) → แสดงในเกม ~128 px
- มนุษย์ทุกคนสูงเท่ากันตามสเปค (ยกเว้นคนแคระอย่าง Bram ~85%) หมวกห้ามนับรวมในความสูงนี้
- มอนสเตอร์: เล็ก (สไลม์) ~120 px, กลาง ~200 px, บอส (หมูป่ามอส) 300–420 px ที่ @2x

## 4. แสงและเงา

- **แสงหลักมาจากด้านบน-หน้า** (top-front, เหนือกล้องเล็กน้อย) ไม่ใช่ซ้ายหรือขวา
  เหตุผล: ภาพ SW/NW คือภาพ SE/NE ที่กลับด้าน ถ้าแสงมาจากซ้าย ภาพกลับด้านจะได้แสงจากขวา ฉากจะดูขัด
- เงาบนตัวละคร: 2 ระดับ (เงากลาง + เงาลึก) สีเงาเลื่อนไปทางม่วง/น้ำเงิน
- **ไม่ต้องวาดเงาพื้นใต้เท้า** เกมวาดวงรีเงาให้เอง (ให้เงาเปลี่ยนตามการกระโดด/เดินได้)
- Rim light บาง ๆ สีอุ่นที่ขอบบน ช่วยแยกตัวละครออกจากพื้นหญ้า

## 5. เส้นขอบและการลงสี

- ขอบตัวละครเป็น **เส้นสีเข้มของสีนั้น ๆ (colored outline)** หนาประมาณ 3–4 px @2x ไม่ใช่เส้นดำ
- ลงสีแบบ cel นุ่ม + texture พู่กันเบา ๆ รายละเอียดเล็กกว่า 4 px @2x จะหายในเกม ไม่ต้องใส่
- **ห้ามมี:** ไล่สีพื้นหลัง, glow ที่เลยขอบภาพ (เช่นงาหมูป่าที่เรืองแสงออกนอกตัว ให้ทำเป็น effect แยก), ประกายฟุ้งรอบตัว, ตัวอักษร, ลายน้ำ

## 6. Palette หลัก (ดึงจาก `02_Environment.png`)

| ชื่อ | Hex | ใช้กับ |
|---|---|---|
| Cobble Peach | `#E2B19A` / `#ECBC9D` | ถนนหิน, ผนังปูน |
| Warm Oak | `#874B27` / `#9D6541` | ไม้ โครงบ้าน รั้ว |
| Shadow Bark | `#4B412E` | เงาไม้, ขอบเข้ม |
| Lantern Amber | `#D38046` / `#E8A56C` | ตะเกียง ไฟ ทองเหลือง |
| Moss Green | `#5C7643` / `#BAC054` | หญ้า มอส ใบไม้ |
| Banner Teal | `#297465` / `#59A982` | ธงเมือง หลังคา ชุดฮีโร่ |
| Brook Aqua | `#3FB8B0` (โดยประมาณ) | น้ำ เวทน้ำ |
| Parchment | `#F2D09B` | กระดาษ UI ไฮไลต์ |

สีอาชีพ/ฝ่าย: นักรบ = เทอร์ควอยซ์+ทองเหลือง, นักเวท = ม่วง+ทอง, ช่าง/สนับสนุน = น้ำตาล+ส้ม, ศัตรูป่า = เทาหิน+เขียวมอส+ส้มเรืองแสง

## 7. ฉากและแผนที่

- แบบ **painted map**: แต่ละแผนที่คือภาพวาดใหญ่ 1 ภาพ (หรือแบ่งเป็นแผ่น 1024×1024) + ชั้น "ของที่บังตัวละคร" แยกไฟล์ (หลังคา, ราวสะพาน, ยอดไม้)
- ทางเดินกว้างอย่างน้อย 3 ตัวละคร; ขอบเขตที่เดินไม่ได้ (น้ำ ผนัง) ต้องดูออกด้วยตา
- พร็อพ (ร้านค้า ถังไม้ ตะเกียง ป้าย) วาดแยกเป็นชิ้นพื้นใสได้ เพื่อนำไปจัดวางซ้ำหลายแผนที่
- ความสว่างฉากต่ำกว่าตัวละครเล็กน้อย (ตัวละครต้องเด่นกว่าพื้นเสมอ)

## 8. UI (จาก `01_concept`)

- กรอบไม้เข้ม + ขอบทองเหลือง, ไอคอนสกิลกรอบสี่เหลี่ยมมุมมน พื้นไล่สีตามธาตุ
- แถบ HP เขียว, MP ฟ้า, ชื่อมอนสเตอร์บอสพร้อมแถบแดงด้านบน
- ฟอนต์ไทย: หัวข้อ **Mitr** / เนื้อหา **IBM Plex Sans Thai** หรือ Sarabun (ทั้งคู่ฟรีบน Google Fonts)
- ชื่อผู้เล่น: ตัวขาวขอบเข้ม + Lv. เล็กใต้ชื่อ (ทำแล้วใน lab)

## 9. Do / Don't

| ✓ ทำ | ✗ ไม่ทำ |
|---|---|
| พื้นหลังสีเดียว **#FF00FF** หรือใสจริง | พื้นหลังลาย/ไล่สี/ฉาก |
| หนึ่งภาพ = ชิ้นเดียวหรือชีตที่เว้นระยะห่างชัด | ชิ้นชนกัน ทับกัน |
| มุมเดียวกันทั้งชุด (SE/NE) | ผสมมุมข้าง มุมตรง ในชีตเดียวกัน |
| แสงบน-หน้า | แสงข้าง |
| หัวกับตัว "แยกไฟล์" สำหรับตัวละครผู้เล่น | หัวติดตัว (ใช้ได้เฉพาะ NPC ที่ไม่เปลี่ยนหมวก) |
