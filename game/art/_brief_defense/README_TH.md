# ชุดคำสั่งวาดภาพ: ปกป้องมงกุฎ (ป้อม ศาล ประตู บอส มอนสเตอร์)

ทุกภาพต้องดูเป็นโลกเดียวกับอัศวินของเรา เลยแนบ `warden_concept.png` (ภาพที่คุณทำไว้) มาในโฟลเดอร์นี้แล้ว
ฝั่งเรา (ป้อม ศาล) ใช้โทน หินสีอ่อน เงิน ทอง น้ำเงิน ฝั่งศัตรู (ประตู บอส มอน) ใช้ หินดำ ลาวา ม่วง

## วิธีใช้

1. เปิดแชทใหม่ใน ChatGPT แนบ `00_CHATGPT_START_HERE.md` แล้วพิมพ์ "ทำตามไฟล์นี้ เริ่มข้อ 1"
2. ทำทีละข้อ ข้อละ 1 ภาพ แนบไฟล์ตามที่บรรทัด `ATTACH WITH THIS PROMPT` บอก แล้ววางข้อความทั้งไฟล์
3. ส่งภาพกลับมาเป็น zip ส่งทีละกลุ่มได้ เช่น ป้อมก่อน ภาพไหนยังไม่มี เกมใช้ภาพชั่วคราวไปก่อน

## เช็กลิสต์ก่อนส่ง

- พื้นหลังโปร่งใส หรือเขียวล้วน `#00FF00` ไม่มีพื้นหญ้า ไม่มีเงาบนพื้น
- ป้อม: 3 ระดับอยู่ภาพเดียว เรียงซ้ายไปขวา ฐานกว้างเท่ากัน ระดับสูงขึ้นทีละนิด ไม่มีส่วนไหนล้นข้ามช่อง
- กำแพงหนาม: กว้างประมาณ 2 เท่าของความสูง
- มุมกล้องเหมือนตัวละคร (มองลงเฉียง) ฐานกลมเห็นเป็นวงรี
- บอสและมอน: ทำแบบตาราง 20 ช่องภาพเดียว หรือแยกแถว `_row1` ถึง `_row5` ก็ได้ เหมือนท่าอัศวิน

ช่องไม่เท่ากันเป๊ะไม่เป็นไร ตัวนำเข้าตัดให้เอง
ที่แก้ทีหลังไม่ได้คือ ทิศผิด ดีไซน์ไม่เหมือนกันในแต่ละช่อง หรือมีพื้นหลังเป็นฉาก ต้องสั่งวาดใหม่
