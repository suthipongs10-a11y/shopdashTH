# Ashen Crown - Crown Defense art (towers, shrine, gate, boss, monsters)

You are making art for a 2D isometric action RPG where a holy knight defends a Crown Shrine from
waves of monsters. Work through the prompt files in order, ONE image per message. Each prompt says
which files to attach. Always attach warden_concept.png when a prompt asks for it: every
structure must look like it belongs to that knight's order (pale stone, silver, gold, royal blue).

## If a 20-pose sheet comes out inconsistent

Tell the owner, then split that sheet into five images, one per direction row. Each image is a
landscape 3:2 canvas with a single row of the 4 frames, using the same prompt text but only the
one row. Name them with a row suffix, for example boss_walk_row1.png to boss_walk_row5.png
(row 1 FRONT, row 2 FRONT-LEFT, row 3 LEFT, row 4 BACK-LEFT, row 5 BACK).

## Do not

- Do not copy characters, names or art from any existing game. The designs are original.
- Do not resize, crop, upscale or convert the results to JPG.
- Do not write code or slice the sheets. The developer does that.
