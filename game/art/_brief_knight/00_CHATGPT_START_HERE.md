# Ashen Crown - new design for the Warden (player knight)

You are making the art for the player character of a 2D isometric action RPG. Work through the
prompt files in order, one image per message. Each prompt says which files to attach.

| Order | Prompt file | Output file |
|---|---|---|
| 1 | prompts/10_warden_concept.txt | warden_concept.png |
| 2 | prompts/11_warden_idle.txt | warden_idle.png |
| 3 | prompts/12_warden_walk.txt | warden_walk.png |
| 4 | prompts/13_warden_attack.txt | warden_attack.png |
| 5 | prompts/14_warden_portrait.txt | warden_portrait.png |

Step 1 is the design reference. Show it to the owner and wait for approval before steps 2 to 5,
and attach the approved warden_concept.png to every later step.

style_reference_knight.png is inspiration for the armour, helmet crest and cape only. Do not draw
the dragon, the ice or the background from it, and do not copy its blue ice colours: the Warden is
silver, gold and royal blue with golden light wings.

## If a 20-pose sheet comes out inconsistent

Tell the owner, then split that sheet into five images, one per direction row. Each image is a
landscape 3:2 canvas with a single row of the 4 frames, using the same prompt text but only the
one row. Name them with a row suffix, for example warden_walk_row1.png to warden_walk_row5.png
(row 1 FRONT, row 2 FRONT-LEFT, row 3 LEFT, row 4 BACK-LEFT, row 5 BACK).

## Do not

- Do not copy characters, names or art from any existing game. The design is original.
- Do not resize, crop, upscale or convert the results to JPG.
- Do not write code or slice the sheets. The developer does that.
