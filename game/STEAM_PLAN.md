# แผนออกแบบ Ashen Crown สำหรับขายบน Steam

เป้าหมาย: เกมเล่นคนเดียว ขายครั้งเดียว บน Steam (PC + Steam Deck) แนวป้องกันมงกุฎ + เก็บเลเวล + สกิลอลังการ

## 1. สิ่งที่ผู้เล่น Steam คาดหวัง (จากรีวิวเกมแนวเดียวกัน)

คำติที่เจอบ่อยในเกม TD/roguelite บน Steam: เนื้อหาน้อย เล่นซ้ำแล้วเหมือนเดิม ตัวละครและสกิลต่างกันไม่พอ
โหมดไม่สิ้นสุดไม่มีเป้าหมาย ความคุ้มค่าไม่สมราคา บาลานซ์แย่ ต้องฟาร์มนาน และประสิทธิภาพต่ำ

หลักการออกแบบที่ตอบโจทย์:

| หลัก | ทำยังไงในเกมเรา |
|---|---|
| "อีกรอบเดียว" | รอบละ 15–25 นาที เริ่มใหม่ได้ทันที จบรอบแล้วมีของใหม่ปลดล็อกเสมอ |
| ความหลากหลายมาก่อนตัวเลข | ความก้าวหน้าถาวรเน้นปลดล็อกของใหม่ (คลาส พร ป้อม แผนที่) มากกว่าบวกค่าพลังแบบฟาร์ม |
| สร้างบิลด์ได้ลึก | พรจับคู่กันเกิดพรขั้นสูง, สกิลมีเส้นทางอัป 2 ทาง, คอมโบธาตุ, ป้อมเสริมกับคลาส |
| ยากแบบยุติธรรม | วงเตือนสีแดงทุกท่าใหญ่, หลบได้, ระดับความยากไต่ขึ้นทีละขั้น ("คำสาปมงกุฎ" แบบ Heat ของ Hades) |
| เห็นตัวเลขชัด | ทูลทิปบอกค่าจริง, สถิติท้ายรอบ, ดาเมจแยกตามสกิล (ผู้เล่นสาย RO/MU ชอบ) |
| ไม่มีจ่ายเพิ่มเพื่อเก่ง | ไม่มีการซื้อในเกม DLC เป็นเนื้อหาใหม่เท่านั้น |
| ลื่นเสมอ | 60 fps แม้เอฟเฟกต์เต็มจอ, มีตัวเลือกลดเอฟเฟกต์/จอสั่น/แฟลช |

## 2. ฟีเจอร์พื้นฐานที่คนซื้อบน Steam ถือว่าต้องมี

| ฟีเจอร์ | สถานะตอนนี้ |
|---|---|
| เสียงและดนตรี (ตีโดน สกิล บอส เพลงต่อด่าน) | ยังไม่มีเลย สำคัญมาก |
| จอยเกม + Steam Deck (ตัวหนังสืออ่านได้ที่ 1280×800, ไม่ต้องใช้เมาส์) | ยังไม่มี (มีปุ่มสัมผัสแล้ว แนวคิดเดียวกัน) |
| เมนูหลัก, หยุดเกม, ตั้งค่า (ความละเอียด เต็มจอ เสียง เปลี่ยนปุ่ม ลดเอฟเฟกต์) | ยังไม่มี |
| เซฟ + Steam Cloud | ยังไม่มี |
| ภาษาอังกฤษ (ผู้ใช้ Steam ราว 39%) และจีนตัวย่อ (ราว 22–31%) | ตอนนี้ไทยอย่างเดียว ต้องวางระบบแปลก่อนข้อความจะเยอะ |
| สอนเล่น 2 นาทีแรก | ยังไม่มี |
| Achievements | ยังไม่มี |
| ภาพจริงครบ (ไม่มีภาพชั่วคราว) | อยู่ระหว่างสั่งวาด |

## 3. ร้านค้าและการตลาดบน Steam

1. เปิดหน้าร้าน "Coming Soon" ให้เร็ว เพื่อสะสม wishlist (ยอด wishlist คือสิ่งที่ Steam ใช้ตัดสินว่าจะโปรโมตเกมเราแค่ไหน)
2. ภาพปก (capsule) + ตัวอย่างวิดีโอที่ 5 วินาทีแรกเห็นสกิลใหญ่และวงเตือนบอส (จุดแข็งของเรา)
3. แท็ก: Action Roguelike, Tower Defense, Hack and Slash, Fantasy, Singleplayer
4. เดโมฟรี → ลง Steam Next Fest ได้ครั้งเดียวต่อเกม ควรมี wishlist 1,000–2,000 ก่อนเข้า
   (Next Fest มิถุนายน 2026 มีเดโมถึง 4,382 เกม แข่งกันสูง)
5. คลิปสั้นท่าสกิล/บอสลง TikTok, YouTube Shorts, X ทุกสัปดาห์ + Discord ของเกม
6. Early Access พร้อมแผนอัปเดตที่ประกาศชัด แล้วอัปเดตฟรีทุก 1–2 เดือน

## 4. ลำดับงานก่อนขึ้น Steam

| ขั้น | งาน | ผลลัพธ์ |
|---|---|---|
| M1 แกนเกมพร้อมขาย | เสียง/ดนตรี, จอย + Steam Deck, เมนูและตั้งค่า, เซฟ, ระบบแปลภาษา + อังกฤษ, สอนเล่น, ภาพจริงชุดแรก | เดโมที่คนนอกเล่นได้โดยไม่ต้องอธิบาย |
| M2 Vertical slice | 1 คลาสเต็ม, 2 แผนที่, บอส 2 ตัว, พร 30+, ป้อม 4 แบบภาพจริง | เปิดหน้าร้าน Coming Soon + เดโม |
| M3 เนื้อหา Early Access | 2–3 คลาส, 3–4 แผนที่, โหมดไม่สิ้นสุด + คำสาปมงกุฎ, Achievements, Steam Cloud | Next Fest แล้วเปิด Early Access |
| M4 หลังเปิดขาย | อัปเดตฟรีตามแผน, จีนตัวย่อ, ตัวเต็ม 1.0 | ยอดรีวิวและยอดขายต่อเนื่อง |

เรื่องเทคนิค: ค่าลงเกม Steam 100 ดอลลาร์ต่อเกม, ต่อ Steamworks (achievements, cloud, overlay) ผ่าน GodotSteam
เกมต้องส่งออกเป็น Windows/Linux (Steam Deck ใช้ Linux หรือ Proton)
