# Ashen Crown (ชื่อชั่วคราว)

เกม Action RPG 2D ทำด้วย Godot 4 โปรเจ็กต์นี้แยกจาก ShopDash โดยสิ้นเชิง แค่ฝากอยู่ใน repo เดียวกัน
เอกสารออกแบบอยู่ที่ [DESIGN.md](DESIGN.md)

## วิธีเปิด

1. ติดตั้ง Godot 4.4 ขึ้นไป (รุ่นมาตรฐาน ไม่ต้องใช้รุ่น .NET)
2. เปิด Godot กด Import แล้วเลือกไฟล์ `game/project.godot`
3. กด F5 เพื่อเล่น

## ปุ่ม

| ปุ่ม | การกระทำ |
|---|---|
| W A S D หรือลูกศร | เดิน |
| เมาส์ | เล็งทิศ |
| คลิกซ้าย หรือ Space | ฟันดาบ |
| Q / E / R | คลื่นดาบ / โล่กระแทก / วงแสงพิทักษ์ |
| F | ท่าไม้ตาย พิพากษา |

## สถานะ

เฟส 1 (แกนต่อสู้) เขียนโค้ดครบแล้ว **แต่ยังไม่เคยรันใน Godot** สคริปต์ผ่านการตรวจไวยากรณ์ด้วย `gdparse` เท่านั้น
ถ้าเปิดแล้วเจอ error ให้ดูที่แท็บ Debugger

## โครงสร้าง

```
project.godot        ตั้งค่าโปรเจ็กต์ (หน้าจอ 1280x720, ฟอนต์ Kanit, autoload Combo)
scenes/main.tscn     ฉากเดียวของเกม ผูกกับ scripts/main.gd
scripts/
  main.gd            สร้างฉากทั้งหมดด้วยโค้ด และลงทะเบียนปุ่ม
  game_data.gd       ตารางสกิล มอนสเตอร์ และฟังก์ชันคำนวณกลาง
  combo.gd           ตัวนับคอมโบ (autoload)
  player.gd          ผู้พิทักษ์: เดิน ค่าพลัง สกิล สูตรดาเมจ
  monster.gd         มอนสเตอร์: เดินเล่น ไล่ตาม ง้าง โจมตี
  spawner.gd         เกิดมอนสเตอร์เป็นฝูงรอบผู้เล่น
  aoe_pulse.gd       เอฟเฟกต์วงพื้น (โล่กระแทก วงแสง พิพากษา)
  blade_wave.gd      คลื่นดาบ
  slash_fx.gd        เส้นฟันดาบ
  damage_number.gd   ตัวเลขลอย
  ground.gd          พื้นภูเขาไฟชั่วคราว
  hud.gd, skill_slot.gd, combo_display.gd   หน้าจอ HUD
fonts/               Kanit (สัญญาอนุญาต OFL)
```

ภาพทั้งหมดตอนนี้เป็นรูปทรงชั่วคราวที่วาดด้วยโค้ดใน `_draw()` ยังไม่มีไฟล์ภาพ
