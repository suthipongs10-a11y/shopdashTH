# Ashen Crown (ชื่อชั่วคราว)

เกม Action RPG 2D ทำด้วย Godot 4 โปรเจ็กต์นี้แยกจาก ShopDash โดยสิ้นเชิง แค่ฝากอยู่ใน repo เดียวกัน
เอกสารออกแบบอยู่ที่ [DESIGN.md](DESIGN.md)

## วิธีเปิด

1. ติดตั้ง Godot 4.4 ขึ้นไป (รุ่นมาตรฐาน ไม่ต้องใช้รุ่น .NET)
2. เปิด Godot กด Import แล้วเลือกไฟล์ `game/project.godot`
3. กด F5 เพื่อเล่น

## ปุ่ม

| ปุ่ม | การกระทำ |
|---|---|
| W A S D หรือลูกศร | เดิน |
| เมาส์ | เล็งทิศ |
| คลิกซ้าย หรือ Space | ฟันดาบ |
| Q / E / R | คลื่นดาบสามสาย / โล่ประกาศิต (กางโล่) / พายุดาบ (หมุนตัว) |
| F | ท่าไม้ตาย คำรามสิงห์ทอง |

## สถานะ

เฟส 1 (แกนต่อสู้) รันได้แล้วใน Godot 4.7 ทดสอบด้วยบอทเล่นอัตโนมัติ: เดิน ฟัน ใช้สกิลครบ 4 ท่า คอมโบ และเลเวลอัป ทำงานโดยไม่มี error
ยังไม่ได้ทดสอบด้วยคนเล่นจริงผ่านคีย์บอร์ดกับเมาส์ และยังไม่ได้ทดสอบการ export

ภาพจริงชุดแรกใส่แล้ว: ตัวเอก (ยืน เดิน โจมตี) โกเลม อิมป์ (เดิน โจมตี) แผนที่ภูเขาไฟ และไอคอนสกิล
สร้างด้วย ChatGPT จากชุดคำสั่งใน `art/_brief/` แล้วแปลงด้วย `tools/import_sprites.py` รายละเอียดอยู่ที่ [ART_GUIDE.md](ART_GUIDE.md)

### ทดสอบด้วยบอท

```
godot --path game -- --autopilot
```

บอทจะเดินหามอนสเตอร์และกดสกิลเอง ใช้สำหรับตรวจว่าเกมไม่พังและอัดภาพตัวอย่าง

## โครงสร้าง

```
project.godot        ตั้งค่าโปรเจ็กต์ (หน้าจอ 1280x720, ฟอนต์ Kanit, autoload Combo)
scenes/main.tscn     ฉากเดียวของเกม ผูกกับ scripts/main.gd
scripts/
  main.gd            สร้างฉากทั้งหมดด้วยโค้ด และลงทะเบียนปุ่ม
  game_data.gd       ตารางสกิล มอนสเตอร์ และฟังก์ชันคำนวณกลาง
  combo.gd           ตัวนับคอมโบ (autoload)
  player.gd          ผู้พิทักษ์: เดิน ค่าพลัง สกิล สูตรดาเมจ
  player_input.gd    แหล่งคำสั่งของผู้เล่น (คีย์บอร์ดกับเมาส์)
  monster.gd         มอนสเตอร์: เดินเล่น ไล่ตาม ง้าง โจมตี
  spawner.gd         เกิดมอนสเตอร์เป็นฝูงรอบผู้เล่น
  sheet_sprite.gd    เล่นท่าทางจากไฟล์สไปรต์ชีต
  fx.gd, ring_fx.gd  เอฟเฟกต์แสง ประกาย ลำแสง และคลื่นกระแทก
  aoe_pulse.gd       ดาเมจวงพื้นของสกิล (กระแทก หมุนดาบ คำราม)
  aegis_fx.gd        ฟองโล่
  lion_fx.gd         วิญญาณสิงโตทอง (ใช้ art/fx/lion_spirit.png ถ้ามี)
  skill_callout.gd   ชื่อสกิลเหนือหัว
  skill_tally.gd     ยอดฮิตและดาเมจรวมต่อการใช้สกิล
  blade_wave.gd      คลื่นดาบ
  slash_fx.gd        เส้นฟันดาบ
  damage_number.gd   ตัวเลขลอย
  ground.gd          พื้นแผนที่ (ภาพจริงถ้ามี ไม่มีก็ใช้ shader)
  hud.gd, skill_slot.gd, combo_display.gd   หน้าจอ HUD
  dev/bot_input.gd   บอทเล่นอัตโนมัติสำหรับทดสอบ
shaders/ground.gdshader   พื้นหินภูเขาไฟชั่วคราว
art/                 ที่วางภาพจริง ดู ART_GUIDE.md
tools/               สคริปต์แปลงภาพดิบเป็นไฟล์เกม และสร้างชุดคำสั่ง/แม่แบบ
fonts/               Kanit (สัญญาอนุญาต OFL)
```
