# ClipFactory — โรงงานคลิปปักตะกร้า

เครื่องมือสำหรับ **affiliate รายเดี่ยว** ที่ต้องผลิตคลิปปักตะกร้าจำนวนมากคนเดียว
ป้อนข้อมูลสินค้า → เลือกสูตรที่พิสูจน์แล้วว่าขายได้ → ระบบเขียนสคริปต์ พากย์เสียงไทย และเรนเดอร์ mp4 แนวตั้งพร้อมโพสต์

> สูตรคลิปทั้ง 9 แบบถอดมาจากคลิป outlier จริงในไทย ก.ค.–ส.ค. 2026
> ดูที่มาได้ที่ [`../research/tiktok-shopee-video/README.md`](../research/tiktok-shopee-video/README.md)

---

## ทำอะไรได้บ้าง

| ขั้น | สิ่งที่ระบบทำให้ |
|---|---|
| 1. ข้อมูลสินค้า | ชื่อ ราคา หมวด จุดขาย กลุ่มลูกค้า |
| 2. เลือกสูตร | 9 สูตรพร้อมหลักฐานคลิปจริง (ยอดวิว + outlier score) · แนะนำสูตรอัตโนมัติตามหมวดสินค้า · กรองตามแพลตฟอร์ม |
| 3. สคริปต์ | Gemini เขียนสคริปต์ไทยตามกฎของสูตรนั้น พร้อม **hook 5 เวอร์ชัน** ให้เลือก แก้ไขได้ทุกบรรทัด |
| 4. เสียงพากย์ | Gemini TTS อ่านให้ทีละบรรทัด เลือกเสียงได้ 8 แบบ และโทนการพูด 4 แบบ — **ไม่ต้องพูดเอง** |
| 5. รูปภาพ | อัปโหลดรูปสินค้าจริง เรียงลำดับได้ ระบบสลับรูปตามจังหวะตัดของสูตร |
| 6. เรนเดอร์ | mp4 9:16 1080×1920 พร้อมซับไทย เขตปลอดภัย และ **เรนเดอร์ทุก hook พร้อมกันเป็นหลายคลิป** |

**สิ่งที่ระบบบังคับให้ถูกต้องตามงานวิจัยโดยอัตโนมัติ**

- Hook อยู่ใน 3 วินาทีแรกเสมอ และห้ามมีคำทักทาย (บังคับผ่าน prompt)
- เปลี่ยนภาพทุก 3–4 วินาทีตามที่สูตรกำหนด (ซอยช็อตอัตโนมัติ)
- ข้อความไม่ตกลงไปในเขตที่ UI ของแพลตฟอร์มบัง — ล่าง 25% และขวา 15%
- ความยาวคลิปคุมอยู่ในช่วงที่สูตรนั้นชนะจริง
- ซับตรงกับเสียงเป๊ะ เพราะไทม์ไลน์สร้างจากความยาวไฟล์เสียงจริง ไม่ใช่การเดา

## เริ่มใช้งาน

```bash
cd clipfactory
pnpm install --ignore-workspace

cp .env.example .env.local
# ใส่คีย์จาก https://aistudio.google.com/apikey ลงในช่อง GEMINI_API_KEY

pnpm dev          # เปิด http://localhost:3000
```

ก่อนลงมือทำคลิปจริง แนะนำให้เปิด **http://localhost:3000/selftest** เพื่อตรวจว่าเบราว์เซอร์เรนเดอร์ได้

### ตัวแปรสภาพแวดล้อม

| ตัวแปร | จำเป็น | ค่าเริ่มต้น |
|---|---|---|
| `GEMINI_API_KEY` | ✅ | — |
| `GEMINI_SCRIPT_MODEL` | | `gemini-2.5-flash` |
| `GEMINI_TTS_MODEL` | | `gemini-2.5-flash-preview-tts` |

คีย์อยู่ฝั่งเซิร์ฟเวอร์เท่านั้น ไม่เคยถูกส่งลงเบราว์เซอร์

## ข้อกำหนดเบราว์เซอร์ (สำคัญ)

การเรนเดอร์ทำในเบราว์เซอร์ด้วย **WebCodecs** — ไม่ต้องติดตั้ง ffmpeg และวิดีโอไม่เคยถูกอัปโหลดขึ้นเซิร์ฟเวอร์

| เบราว์เซอร์ | ผล |
|---|---|
| **Google Chrome / Microsoft Edge** | ✅ ได้ H.264 + AAC — อัปโหลดขึ้น TikTok และ Shopee ได้ทันที |
| Chromium ที่ไม่มี codec ลิขสิทธิ์ (เช่นบางดิสโทรของ Linux) | ⚠️ ถอยไปใช้ VP9 + Opus ระบบจะเตือน — ไฟล์เล่นได้แต่แพลตฟอร์มอาจไม่รับ |
| Safari / Firefox | ❌ ยังไม่รองรับ WebCodecs ครบ |

**แนะนำให้ใช้ Chrome หรือ Edge**

## โครงสร้างโค้ด

```
app/
  page.tsx              หน้าทำงานหลัก (client) — ประสานทุกขั้นตอน
  selftest/page.tsx     ทดสอบว่าเครื่องเรนเดอร์ได้ ไม่เรียก Gemini
  api/script/route.ts   เขียนสคริปต์ด้วย Gemini (structured output)
  api/tts/route.ts      พากย์เสียงด้วย Gemini TTS → คืนไฟล์ wav
  api/health/route.ts   บอก UI ว่าตั้งคีย์แล้วหรือยัง
lib/
  templates.ts          ★ 9 สูตรคลิปในรูปแบบ "ข้อมูล" — เพิ่มสูตรใหม่ได้โดยไม่แตะ engine
  types.ts              โครงสร้างข้อมูลกลาง + ค่ามาตรฐาน 9:16 และเขตปลอดภัย
  gemini/               client, script (prompt + schema), tts (PCM → WAV)
  render/
    timeline.ts         สคริปต์ + ความยาวเสียงจริง → ไทม์ไลน์ช็อต
    draw.ts             วาดเฟรม: Ken Burns, headline, ซับ, เขตปลอดภัย
    text.ts             ตัดบรรทัดภาษาไทยด้วย Intl.Segmenter
    audio.ts            ผสมเสียงพากย์ + เพลง ด้วย OfflineAudioContext
    encode.ts           WebCodecs + mp4-muxer → ไฟล์ mp4
components/             ส่วนติดต่อผู้ใช้ทีละขั้น
scripts/verify-render.mjs   ทดสอบไปป์ไลน์เรนเดอร์ด้วย Chromium จริง
```

### กติกาของโค้ดฐานนี้

1. **สูตรคลิปคือข้อมูล ไม่ใช่โค้ด** — ห้ามเขียน `if (templateId === 'listicle')` ที่ไหนก็ตาม ความต่างทุกอย่างต้องมาจากค่าใน `lib/templates.ts`
2. **คีย์ Gemini อยู่ฝั่งเซิร์ฟเวอร์เท่านั้น** — ไฟล์ใน `lib/gemini/` ต้อง `import 'server-only'`
3. **ข้อความที่ผู้ใช้เห็นเป็นภาษาไทยทั้งหมด** รวมถึงข้อความ error — โค้ดและชื่อตัวแปรเป็นอังกฤษ
4. **ไทม์ไลน์ต้องสร้างจากความยาวเสียงจริง** เมื่อมีเสียงพากย์แล้ว ห้ามใช้ค่าประมาณ ไม่อย่างนั้นซับกับเสียงจะเหลื่อม
5. แก้สคริปต์แล้ว **ต้องล้างเสียงที่เกี่ยวข้องทิ้ง** เพื่อกันคลิปที่เสียงกับข้อความไม่ตรงกัน

## ทดสอบ

```bash
pnpm typecheck        # ตรวจชนิดข้อมูล
pnpm build            # build production
pnpm verify:render    # เรนเดอร์คลิปจริงด้วย Chromium แล้วตรวจโครงสร้างไฟล์ mp4
```

`pnpm verify:render` จะตรวจครบตั้งแต่วาด canvas ภาษาไทย ผสมเสียง เข้ารหัสวิดีโอและเสียง
ไปจนถึงแกะกล่อง (box) ของไฟล์ mp4 ว่ามี `ftyp` `moov` `mdat` ครบ มี 2 track และ `moov` มาก่อน `mdat` (fast start)

ถ้าเครื่องมี Chromium อยู่แล้ว ให้ชี้ path ตรงๆ เพื่อไม่ต้องดาวน์โหลดใหม่:

```bash
CHROMIUM_PATH=/path/to/chrome pnpm verify:render
```

## ข้อจำกัดที่รู้อยู่แล้ว

- **ยังไม่โพสต์อัตโนมัติ** — ระบบส่งออกไฟล์ให้ดาวน์โหลด แล้วนำไปอัปโหลดและปักตะกร้าเองในแอป
- **ยังไม่มี feedback loop** — ยังไม่ดึงยอดวิว/ยอดขายกลับมาจัดอันดับสูตร (อยู่ในเฟส P3 ของแผน)
- **ยังไม่ดึงข้อมูลสินค้าจากลิงก์อัตโนมัติ** — ต้องกรอกเอง
- **เพลงประกอบต้องอัปโหลดเอง** และควรใช้จากคลังเพลงเชิงพาณิชย์ของแพลตฟอร์มเท่านั้น
- คลิปยาวเกิน ~60 วินาทีจะใช้แรมมาก เพราะเก็บไฟล์ไว้ในหน่วยความจำทั้งก้อนก่อนดาวน์โหลด

## หลักการที่ยึดไว้

งานวิจัยชี้ชัดว่าตลาดนี้ชนะด้วย **ความจริง** ไม่ใช่ความสวย
เครื่องมือนี้จึงออกแบบให้ **ประกอบคลิปจากรูปสินค้าจริงที่ผู้ใช้ถ่ายเอง** แล้วช่วยเรื่องสคริปต์ เสียง จังหวะตัด และเขตปลอดภัย
ไม่ใช่การ generate ฉากปลอมทั้งคลิป ซึ่งเป็นสิ่งที่ทำให้คลิปทำยอดได้แย่ลง
