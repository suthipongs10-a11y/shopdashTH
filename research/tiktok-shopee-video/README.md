# Research: วิดีโอ "ปักตะกร้า" TikTok Shop & Shopee Video (ไทย) — สิงหาคม 2026

> **เป้าหมายของเอกสาร:** หาว่า *คลิปแบบไหน* กำลังมาแรงและ **ขายได้จริง** บน TikTok Shop / Shopee Video ในไทยตอนนี้
> เพื่อใช้เป็น spec ตั้งต้นของ **เครื่องมือผลิตวิดีโอปักตะกร้าอัตโนมัติ** ที่จะสร้างต่อ
>
> **แหล่งข้อมูล:** (ก) ข้อมูล outlier จริงจาก TikTok + Instagram Reels ไทย ช่วง 30 วันล่าสุด — คลิปที่ทำยอดสูงกว่า median ของครีเอเตอร์ตัวเองหลายสิบถึงหลายร้อยเท่า วิเคราะห์ผ่าน vidIQ (ข) บทความ/สถิติอุตสาหกรรม 2026
> **วันที่ทำ research:** 15 ส.ค. 2026 · **สถานะ:** งานวิจัยตั้งต้น (ยังไม่ได้ทำ tool)

## 1. บทสรุปผู้บริหาร (อ่านแค่ส่วนนี้ก็พอ)

**ข้อค้นพบที่สำคัญที่สุด 6 ข้อ:**

1. **คลิป "listicle พูดหน้ากล้อง" คือสูตรที่ชนะขาดในไทยตอนนี้** — รูปแบบ *"5 อย่างที่ซื้อแล้วไม่เสียดายเงิน"* ยาว **11–18 วินาที** ถ่ายกล้องนิ่ง เสียงพูดล้วน (ไม่มีเพลง) ข้อความ overlay ตัวเดียว ทำยอดได้ **1.1–1.4 ล้านวิว** ซ้ำๆ กันหลายบัญชี ต้นทุนผลิตต่ำสุดในบรรดาทุกรูปแบบ (< 1 ชม./คลิป)
2. **โปรดักชันสวยแพ้ความ "จริง"** — คลิปที่ชนะเกือบทั้งหมดถ่ายด้วยมือถือ กล้องนิ่ง ไม่มี transition หวือหวา ข้อมูลตรงกับที่ TikTok เองระบุว่า raw product demo + รีวิวจริง performance ดีกว่า brand ad ที่ขัดเงามาแล้ว
3. **บัญชีเล็กยังมีโอกาสมหาศาล** — ในชุดข้อมูลมีบัญชี **317 followers ได้ 153K วิว**, **981 followers ได้ 907K วิว**, **394 followers ได้ 11K วิว** → อัลกอริทึมไทยยังกระจาย reach ตามคุณภาพคอนเทนต์ ไม่ใช่ขนาดบัญชี **แปลว่า strategy "ผลิตเยอะ + หลายบัญชี" ยัง work** และนั่นคือช่องว่างที่ tool จะเข้าไปเติม
4. **Hook 3 วินาทีแรกคือทุกอย่าง** — ทั้ง TikTok และ Shopee ยืนยันตรงกัน คลิปที่ชนะเปิดด้วย **ปัญหา / ตัวเลข / ข้อความยั่ว** ทันทีวินาทีที่ 0 ไม่มีคลิปไหนเสียเวลาทักทาย
5. **Shopee Video ≠ TikTok** — Shopee คนดูมาด้วย *เจตนาซื้อ* อยู่แล้ว คลิปสั้นกว่า (**10–30 วิ**) เน้น before/after + คูปองเด้งกลางคลิป ส่วน TikTok ต้องแย่ง attention จาก feed บันเทิงก่อน → hook ต้องแรงกว่า
6. **9 สูตรคลิปที่ทำซ้ำได้** (ตารางในหัวข้อ 3) → นี่คือ **template library** ที่ tool ควรมีตั้งแต่ v1

**นัยต่อการสร้างเครื่องมือ:** สิ่งที่ควรสร้างไม่ใช่ "AI ทำวิดีโอสวยๆ" แต่คือ **โรงงานผลิตคลิปสูตรสำเร็จจำนวนมาก** — ป้อนลิงก์สินค้าเข้าไป ได้คลิป 9:16 พร้อมโพสต์ออกมา 5–10 เวอร์ชัน (สลับ hook) ต่อสินค้า 1 ชิ้น ภายในไม่กี่นาที

## 2. ภาพตลาด 2026

### 2.1 TikTok Shop
| ตัวเลข | ค่า |
|---|---|
| GMV ทั่วโลก 2026 (คาดการณ์) | มุ่งสู่ **$100 พันล้าน** |
| GMV TikTok Shop SEA ปี 2025 | ~**$45.6 พันล้าน** (≈71% ของ GMV โลก) |
| อันดับไทย | Top 5 ของโลก / รองจากอินโดนีเซีย ในกลุ่ม SEA |
| Benchmark ที่ควรวัด (TikTok แนะนำ) | Conversion Rate **3–5%**, Add-to-Cart **10–15%**, Return Rate **< 5%** |

**สิ่งที่เปลี่ยนในปี 2026:** ระบบ **GMV Max** (แคมเปญ AI อัตโนมัติของ TikTok Shop — เปิดใช้ในไทยแล้ว) จะ**ดึงคลิป affiliate ที่ได้รับอนุญาตไปยิงแอดให้เอง** โดยอัตโนมัติ

> ⚠️ **นี่คือจุดเปลี่ยนเชิงกลยุทธ์:** คลิปปักตะกร้าไม่ได้มีค่าแค่ organic view อีกต่อไป — คลิปที่ดีจะถูก GMV Max หยิบไปเป็น ad creative ต่อ ทำให้ **"จำนวนคลิปคุณภาพต่อสินค้า" กลายเป็นสินทรัพย์โดยตรง** และยิ่งตอกย้ำว่าเครื่องมือผลิตคลิปจำนวนมากมีมูลค่าสูง

## 4. กายวิภาคของคลิปที่ขายได้ (สรุปเป็น spec)

| องค์ประกอบ | ค่าที่ชนะจากข้อมูลจริง |
|---|---|
| **ความยาว** | **11–18 วิ** (listicle) · **20–45 วิ** (demo) · **50–120 วิ** (trust/educational) — ข้อมูลอุตสาหกรรมชี้ว่า 10–18 วิ กำลังชนะ 30+ วิ ในสาย affiliate |
| **0–3 วินาที** | ปัญหา / ตัวเลข / ข้อความยั่ว — **ห้ามทักทาย ห้ามอินโทร** |
| **เสียง** | Listicle = **เสียงพูดล้วน** · Demo = เสียงพูด + เพลงเบาๆ · Stop-motion = เพลงล้วน |
| **กล้อง** | นิ่งสนิทได้ผลดีมาก — คลิป 1M+ วิวหลายตัวคือ static camera |
| **Text overlay** | Static 1 ประโยค (listicle) / Dynamic caption (deal & demo) |
| **Pacing** | เปลี่ยนภาพทุก 3–4 วินาที หรือใช้ zoom in/out ในฉากเดิม |
| **Loop** | ทำจบให้ต่อหัวได้ = watch time เพิ่มฟรี (พบใน demo หลายตัว) |
| **CTA** | "กดตะกร้าเหลืองข้างล่าง" ใส่ท้ายคลิป + text overlay ชี้ลง |
| **Safe zone 9:16** | 1080×1920 · เว้นล่าง ~25% (caption + ตะกร้า) และขวา ~15% (ปุ่ม UI) |

## 5. TikTok vs Shopee Video — ต้องทำคลิปต่างกัน

| | **TikTok Shop** | **Shopee Video** |
|---|---|---|
| เจตนาคนดู | มาเสพความบันเทิง → ต้อง**แย่ง**ความสนใจ | มาช้อปอยู่แล้ว → **ตัดสินใจซื้อ** |
| ความยาวที่ดีที่สุด | 11–18 วิ (listicle) / 20–45 วิ (demo) | **10–30 วิ** |
| Hook | ต้องแรงมาก (ปัญหา/ดราม่า/ตัวเลข) | ตรงประเด็นได้เลย เห็นผลไว |
| กลไกแปลงยอด | ตะกร้าเหลือง + GMV Max ดึงคลิปไปยิงแอด | **คูปองเด้งกลางคลิป** + ลิงก์สินค้า |
| คอมมิชชั่น | ตามร้าน/แคมเปญ | สูงสุด 30% (คลิป) / สูงสุด 50% (live: 10% Shopee + 40% แบรนด์) |
| แฮชแท็ก | แคมเปญ double-date, `#ของดีบอกต่อ`, `#รีวิวบิวตี้` | `#ShopeeVideoTH`, `#รีวิวของดี` + หมวดสินค้า |
| กลยุทธ์ tool | ผลิตหลาย hook ต่อสินค้า, ยาว 15 วิ | **รีไซเคิลคลิปเดิม** ตัดสั้นลง + ใส่คูปอง |

> 💡 **โอกาสของเครื่องมือ:** สร้างคลิป master 1 ตัว → **auto re-cut** เป็นเวอร์ชัน TikTok (15 วิ hook แรง) และเวอร์ชัน Shopee (10–20 วิ ตรงประเด็น + จุดแทรกคูปอง) พร้อมกัน

## 6. หมวดสินค้าที่ปักตะกร้าแล้วไปได้ดี (จากข้อมูล)

| หมวด | ความถี่ในชุด outlier | สูตรที่เข้ากัน |
|---|---|---|
| **ความงาม/สกินแคร์** | สูงสุด (~40%) | listicle, proof test, before/after |
| **ของใช้ในบ้าน / ทำความสะอาด** | สูงมาก | problem→solution demo |
| **แฟชั่นราคาย่อมเยา** | ปานกลาง | listicle, haul |
| **เครื่องใช้ไฟฟ้าชิ้นเล็ก** (เครื่องดูดฝุ่น, กรองน้ำ) | ปานกลาง | demo + b-roll |
| **ของกิน/ขนม** | ปานกลาง | seller POV, showcase |
| **มือสอง/ไอที งบจำกัด** | น้อยแต่ยอดดี | listicle ราคา |

**เทรนด์เฉพาะไทย 2026 ที่บทความชี้:** อาหาร/เกษตรแปรรูปเพื่อสุขภาพ (ผลไม้อบแห้ง, เครื่องดื่มสมุนไพรลดน้ำตาล) และ **"Thai Clean Beauty"** สมุนไพรไทย

## 7. สิ่งที่ "ไม่" เวิร์ก / ความเสี่ยงที่ต้องออกแบบเผื่อ

1. **คลิปโปรดักชันสวยเนียนแบบโฆษณา** — แพ้ raw content สม่ำเสมอ (ทั้งข้อมูล outlier และ TikTok เองยืนยัน)
2. **Hard sell ตรงๆ** — soft selling (แทรกสินค้าในคอนเทนต์บันเทิง/ให้ความรู้) engagement สูงกว่าราว **73%**
3. **คลิปแคมเปญมีอายุสั้นมาก** — สูตร 3 ตายทันทีเมื่อจบแคมเปญ ต้องมีปฏิทินและ auto-expire
4. **ปัญหาของปลอมกำลังกัดกร่อนความเชื่อมั่น** — คลิปเตือนภัยได้ยอดสูงมาก = สัญญาณว่าผู้บริโภคกำลังระแวง → **tool ควรมีระบบ disclosure/ระบุร้าน official** ไม่ใช่ปั๊มคลิปมั่ว
5. **AI-generated ที่ดู "เป็น AI" ชัดๆ** ขัดกับหัวใจของตลาดนี้คือ "ความจริง" → เครื่องมือควรเน้น **ประกอบคลิปจากภาพ/วิดีโอสินค้าจริง** + VO + ตัดต่อ มากกว่า generate ฉากปลอมทั้งคลิป (ความเสี่ยงหลักของโปรเจ็คนี้)
6. **ยิงรัวจนโดนมองเป็น spam** — ต้องคุมจำนวนโพสต์/บัญชี/วัน และหมุน hook ไม่ให้ซ้ำ

## 8. Blueprint เครื่องมือที่ควรสร้าง

### 8.1 นิยาม
> **ไม่ใช่** "AI สร้างวิดีโอสวยๆ" — **แต่คือ "โรงงานผลิตคลิปปักตะกร้าตามสูตรสำเร็จ จำนวนมาก"**
> ป้อนลิงก์สินค้า 1 ชิ้น → ได้คลิป 9:16 พร้อมโพสต์ **5–10 เวอร์ชัน** (สลับ hook / สลับ template) ภายในไม่กี่นาที

### 8.2 Pipeline

```
[1] INPUT
    ลิงก์สินค้า TikTok Shop / Shopee  หรือ  กรอกเอง (ชื่อ, ราคา, จุดขาย, รูป)
      ↓
[2] TEMPLATE SELECT
    เลือกจาก 9 สูตร (หัวข้อ 3) — เก็บเป็น "ข้อมูล" ใน DB ไม่ใช่ hardcode
    ระบบแนะนำสูตรตามหมวดสินค้าอัตโนมัติ (ความงาม→listicle/proof, ของใช้บ้าน→demo)
      ↓
[3] SCRIPT GEN (LLM)
    สร้างสคริปต์ไทย: hook 3 วิ (5 เวอร์ชัน) + body ตามโครง template + CTA ปักตะกร้า
    บังคับกฎ: ห้ามทักทาย, ประโยคสั้น, ภาษาพูดจริง, ความยาวคุมเป็นวินาที
      ↓
[4] ASSET GEN
    • VO ภาษาไทย (TTS) — น้ำเสียงคุยธรรมชาติ ไม่ใช่โฆษณา
    • ภาพ/วิดีโอสินค้า — ใช้ของจริงจาก listing เป็นหลัก, เสริมด้วย generate เฉพาะ b-roll
    • ซับไทยอัตโนมัติ (word-level timing)
    • เพลง — เลือกจาก TikTok Commercial Music Library (ปลอดลิขสิทธิ์เชิงพาณิชย์)
      ↓
[5] RENDER
    9:16 1080×1920 · safe zone (เว้นล่าง 25% / ขวา 15%) · ตัดทุก 3–4 วิ · ทำ loop ให้เนียน
      ↓
[6] VARIANT FACTORY
    1 สินค้า → N คลิป (สลับ hook × สลับ template × สลับความยาว)
    + auto re-cut เวอร์ชัน Shopee (สั้นลง + mark จุดแทรกคูปอง)
      ↓
[7] PRE-FLIGHT SCORE
    ทำนายศักยภาพไวรัล / ความแรง hook ก่อนโพสต์ → ทิ้งตัวที่คะแนนต่ำ
      ↓
[8] PUBLISH + FEEDBACK LOOP
    โพสต์ตรง (หรือ export) → ดึงยอดวิว/CTR/ยอดขายกลับมา → จัดอันดับ template & hook ใหม่
    ⟲ ยิ่งใช้ยิ่งฉลาด (นี่คือ moat ตัวจริงของเครื่องมือ)
```

### 8.3 ของที่มีอยู่ในมือแล้ว (MCP ที่เชื่อมในเซสชันนี้)

| ขั้นตอน | เครื่องมือที่ใช้ได้ทันที |
|---|---|
| หา outlier / วิเคราะห์คู่แข่ง | `vidiq_instagram_tiktok_outlier_search`, `vidiq_watch_shortform_content` |
| สร้างสคริปต์ / ชื่อคลิป | `vidiq_generate_script`, `vidiq_generate_titles` |
| B-roll / คลิป / เสียงพากย์ | `higgsfield.generate_video`, `generate_image`, `generate_audio`, `vidiq_voiceover_generate` |
| ตัดต่อสั้น / ซับ | `vidiq_generate_clips`, `higgsfield.shorts_studio_create` |
| เพลงจาก TikTok CML | `higgsfield.tiktok_music_trending` |
| ทำนายไวรัลก่อนโพสต์ | `higgsfield.virality_predictor` |
| โพสต์ขึ้น TikTok | `higgsfield.tiktok_publish` |

> ✅ **สรุป: pipeline ทั้งเส้นมีชิ้นส่วนพร้อมแล้ว** สิ่งที่ต้องสร้างเองคือ **template library (9 สูตร) + orchestration + feedback loop**

### 8.4 ข้อเสนอ scope เป็นเฟส

| เฟส | ส่งมอบ | เกณฑ์ผ่าน |
|---|---|---|
| **P0** | ป้อนลิงก์สินค้า → ได้ **สคริปต์ + storyboard** ไทย 5 เวอร์ชัน (ยังไม่เรนเดอร์) | คนถ่ายเองตามสคริปต์แล้วได้คลิปที่ใช้งานจริง |
| **P1** | Auto-render สูตร 1 (listicle) + สูตร 8 (stop-motion) เป็น mp4 9:16 พร้อมโพสต์ | โพสต์จริง 20 คลิป วัดยอดเทียบคลิปทำมือ |
| **P2** | ครบ 9 สูตร + re-cut Shopee + pre-flight score | ผลิต ≥ 50 คลิป/วัน โดยคนคุม 1 คน |
| **P3** | Publish อัตโนมัติ + feedback loop จัดอันดับ template | CTR/ยอดขายต่อคลิปดีขึ้นจากรอบก่อนอย่างมีนัยสำคัญ |

### 8.5 คำถามที่ต้องตัดสินใจก่อนเริ่มสร้าง
1. **ผู้ใช้เป้าหมาย** — affiliate รายเดี่ยว, ร้านค้า, หรือเอเจนซี? (กระทบ pricing และ multi-account)
2. **โมเดล** — SaaS รายเดือน / จ่ายตามจำนวนคลิป / ใช้เองเพื่อทำ affiliate?
3. **ระดับความ auto** — ผลิตให้แล้วคนเลือกก่อนโพสต์ (ปลอดภัยกว่า) หรือโพสต์อัตโนมัติเต็ม?
4. **แหล่งฟุตเทจ** — ดึงรูป/วิดีโอจาก listing (ต้องดูเงื่อนไขลิขสิทธิ์) หรือให้ผู้ใช้อัปโหลดเอง?
