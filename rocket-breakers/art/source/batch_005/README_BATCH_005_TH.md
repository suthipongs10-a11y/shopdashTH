# ROCKET BREAKERS — BATCH 005

ส่งมอบไอคอน HUD ครบ 12 PNG ตามชื่อที่ร้องขอ สร้างทีละภาพด้วยเครื่องมือสร้างภาพในตัว

- ทุกภาพเป็น RGBA มี alpha จริง ช่วง 0–255 ไม่มีพื้นหลังทึบ ตรวจบนพื้นมืดและขาวแล้ว
- ขนาดจริงทุกภาพ 1254×1254 พิกเซล (คำขอ 512×512 อัตราส่วน 1:1 ตรงกัน) เก็บต้นฉบับโดยไม่ย่อหรือแก้พิกเซล
- กึ่งกลาง canvas/pivot แบบ normalized = (0.5,0.5) หรือ (627,627) สำหรับไฟล์จริง ต้องปรับ optical alignment/scale ในเกมเพื่อให้ไอคอนต่างทรงดูสมดุล
- วงแหวนข้อต่อมีสามช่องขาด โล่เกราะเป็นรูปปิด
- Tractor ใช้รุ่นแก้ไขแม่เหล็กกับลำแสงดึงชิ้นส่วน; Repair ใช้รุ่นแก้ไขประแจกับเครื่องหมายบวก ไม่นำรุ่นแรกมาส่ง
- ไม่มีส่วนที่มองเห็นถูกตัดขอบ (alpha>16) บางภาพมี alpha 1 ที่ขอบ เป็นสัญญาณจางมาก ควรตรวจขอบ atlas ก่อนปล่อยจริง
- ตรวจภาพย่อ 32 px เบื้องต้นแล้ว รายละเอียด turbine/cargo จะลดลง ต้องทดสอบความอ่านง่ายบน HUD และอุปกรณ์จริง โดยเฉพาะ cargo hook
- ยังไม่ผ่านการทดสอบในเอนจินหรืออนุมัติขั้นสุดท้าย

แตก ZIP ทั้งสามลงโฟลเดอร์เดียวกัน แต่ละไฟล์เป็น ZIP อิสระ ไม่ใช่ split archive
PART 01: dash, overdrive, tractor, lock_joint
PART 02: locked_armor, heat, energy, cargo
PART 03: repair, pause, play, settings
