# ROCKET BREAKERS — BATCH_001

สร้างครบ10รายการของ BATCH_001 ตามแพ็กคำขอใหม่ เป็นPNGชิ้นแยก ไม่ใช่ภาพบอร์ดรวม รายการอื่นใน41ชุดยังไม่ได้สร้างในรอบนี้

## ไฟล์ที่ส่ง

- PART_01: ตัวยานH01เปล่า แสงเครื่องยนต์ ปืนW001 เลเซอร์W008 หางที่ผู้เล่นยึดได้W022 และเอกสารรายงาน
- PART_02: ตัวบอสB02ที่ไม่มีหาง และข้อต่อวงแหวน
- PART_03: หางขนาดบอส เกราะปิดข้อต่อ และแสงมัดสายลาก

แตกZIPทั้ง3ลงตำแหน่งเดียวกัน จะรวมเป็นโฟลเดอร์ RB_BATCH_001_DELIVERY ชื่อPNGตรงคำขอทุกไฟล์ ไม่มีไฟล์ .z01 ที่ต้องใช้โปรแกรมต่อไฟล์

## ขนาดจริงและสถานะ

ทุกภาพมีขนาดจริง1254×1254พิกเซล และมีRGBAalphaโปร่งใส ขนาดนี้ต่างจากเป้าหมาย512/1024ในคำขอ ระบบสร้างภาพให้ขนาดดังกล่าว จึงส่งต้นฉบับโดยไม่แก้ตัวเลขหรืออ้างว่าขนาดตรงแล้ว ดูrequested_canvasและactual_canvasในdelivery_manifest.json

Claudeควรย่อภาพในขั้นตอนimport/ทำสำเนาnormalizedตามเป้าหมาย ตรวจตำแหน่งmuzzle/socket/coreและปรับจุดยึดก่อนนำเข้าเกม อย่าใช้เพียงการหารอัตราส่วนcanvasแล้วถือว่าตำแหน่งตรงทุกชิ้น เพราะภาพสร้างอาจจัดวางคลาดจากตัวเลขที่ขอ pivotและsocketยังต้องตรวจในเกม สถานะคือgenerated_awaiting_engine_QA ไม่ใช่approved/integrated

## การตรวจที่ทำแล้ว

- ครบชื่อไฟล์และรายการ10/10 เปิดPNGได้ และมีช่องalphaจริงทุกไฟล์
- วัตถุที่มองเห็นหลักไม่ถูกตัดขอบ ตรวจด้วยalpha>16 และตรวจภาพด้วยสายตา ขอบโปร่งใสอาจมีnoisealphaระดับต่ำมาก จึงต้องตรวจการcompositeและedge cleanupตอนimportก่อนrelease
- ตัวยานไม่มีปืน/จรวดหรือเปลวเครื่องยนต์ฝังอยู่ ตัวบอสไม่มีหางฝังอยู่
- หางผู้เล่นกับหางบอสใช้ลายปล้อง/หัวพลาสมาเดียวกัน ต่างไฟบอกเจ้าของcyan/red
- แยกข้อต่อเปิดกับเกราะปิดเป็นคนละภาพ
- แก้ร่างแรกที่แสงเครื่องยนต์ชนขอบ ปืนเข็มยาวเกินช่องเดียว และตัวบอสหันหัวลงแล้ว ส่งเฉพาะร่างที่เลือกสุดท้าย

ยังไม่ได้ทดสอบanchor/collider/ขนาดเมื่อย่อบนมือถือ/ภาพoverlayในGodot และยังไม่ใช่แอนิเมชันพร้อมใช้ ทั้งหมดต้องผ่านClaudeตรวจในเกมตามขั้นตอนในแพ็กคำขอ
