# ROCKET BREAKERS — BATCH 008

ส่งมอบศัตรู E05–E16 ครบ 12 PNG ตามชื่อไฟล์ในคำขอ สร้างทีละภาพด้วยเครื่องมือสร้างภาพในตัว
ใช้ enemies_board เป็นแนววัสดุและสไตล์ ไม่ตัดภาพจากบอร์ด

ขนาดจริงทุกภาพ 1254×1254 พิกเซล (คำขอ 512×512 อัตราส่วน 1:1 ตรงกัน) เก็บต้นฉบับ ไม่ย่อหรือแก้พิกเซล
ทุกภาพ RGBA alpha จริง 0–255 ตรวจพื้นดำ ขาว และตารางแล้ว ไม่มีพื้นหลังทึบหรือ checkerboard วาดติดภาพ
ไม่มีส่วนที่มองเห็นถูกตัดขอบที่ alpha>16 บางไฟล์มี alpha จางมาก 1/255 ที่ขอบ ควรตรวจ atlas bleed
Ash Bomber มีปีกกว้างและระยะขอบด้านข้างประมาณ 43 px จึงมี padding น้อยกว่าลำอื่น ควรเผื่อ atlas extrusion ตอนนำเข้า
Storm Pylon และ Sand Mortar ส่งรุ่นแก้มุมบน ไม่รวมรุ่นแรกที่มุมเอียง

## สำหรับ Claude
manifest จับคู่ enemy_id/name/role/move/attack ตาม BATCH_008 พร้อมขนาด alpha bbox และ SHA256
รูปเป็นชั้นยานพื้นฐาน ไม่มีภาพโจมตีแยก/แอนิเมชันหรือ hitbox ที่ทดสอบแล้ว พฤติกรรมและ joints ต้องสร้างใน code ตามคำขอ
ทิศหน้าอ้างอิง = ขึ้น (0,-1) ให้เอนจินหมุนเข้าหาผู้เล่นเอง; ทรงป้อมสมมาตรใช้ tab/อาวุธด้านบนช่วยกำหนดทิศ
จุดกลาง canvas จริง=(627,627) หรือ normalized=(0.5,0.5) เป็นจุดเริ่มต้น ไม่ใช่ pivot มวลของทุกลำ
ปรับ world scale รายชนิด อย่าให้ Thorn Swarm ใหญ่เท่ายานทิ้งระเบิดเพียงเพราะ canvas เท่ากัน
Cable Cutter ไม่สมมาตร มีใบมีดยื่นด้านข้าง ต้องตั้ง hitbox/จุดหมุนให้ตรงลำตัวและการฟัน แยก attack collider ใน code
Root Healer ใช้แขนเขียวเป็นสัญลักษณ์ซ่อม ยังเป็นฝ่ายศัตรูจากเกราะ/ไฟแดง
Ice Diver ใช้ผลึกฟ้า, Drill Diver ใช้หัวสว่าน, Furnace Drone ใช้ปากเตาส้ม, Ion Skater ใช้ขดลวดฟ้า
ภาพย่อ 48px ตรวจเบื้องต้นแล้ว รายละเอียดกลไกจะลดลง ต้องตรวจความอ่านง่าย สเกลและ collision ในเกมจริง รวมทั้งความสว่างบนฉากมืด
