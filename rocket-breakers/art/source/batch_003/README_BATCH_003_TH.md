ชุดนี้มี10ภาพแยกตามคำขอที่ดาวน์โหลดใหม่จากGitHub: E01/E03/E02/E04, H01เอียงซ้าย/ขวา, ชั้นรอยเสียหายH01/B02, Patch Plating T001 และTow Winch T006

## สถานะ

ทุกภาพเป็นgenerated_awaiting_engine_QA ไม่ใช่approved/integrated ตรวจdecode,alphaและขอบวัตถุที่มองเห็นในdelivery_manifest.json เป้าหมาย512/1024และขนาดจริงบันทึกแยกกัน ห้ามเดาขนาดจากชื่อไฟล์

ท่าเอียงและรอยเสียหายอ้างอิงPNGจริงจากBATCH_001ที่แนบมาในZIPคำขอ ภาพเหล่านี้สร้างด้วยโมเดลภาพจึงยังไม่รับรองว่าจุดยึดทับตรงทุกพิกเซล ให้Claudeตรวจcore/muzzle/socketและซ้อนภาพกับต้นฉบับในengineก่อนใช้ หากต้องย่อ/เลื่อน/แก้edgeให้ทำเป็นสำเนาimportและเก็บต้นฉบับไว้

## การใช้ภาพ

- ศัตรูหันหัวขึ้นในsource sprite ให้engineหมุนตามทิศเดิน ไม่ฝังทิศผู้เล่นลงในtexture
- ท่าleanเป็นการเอียงลำตัวเล็กน้อย ไม่ใช้ภาพไปเปลี่ยนhurtboxหรือsocketตามทรงวาดทุกเฟรม
- damage_overlayเป็นชั้นรอยไหม้ รอยแตก ลวดและประกายแยก ไม่มีbodyเต็มตัว ควรclipด้วยmaskของลำตัวต้นฉบับในruntimeเพื่อไม่ให้รอยลอยนอกยาน ข้อมูลความทับซ้อนในรายงานเป็นตัวช่วยตรวจ ไม่ใช่ผลผ่านanchor
- T001เป็นเกราะเสริม1ช่อง T006เป็นกว้านสายลาก1ช่อง ไม่ใช่ปืนยิง พิกัดจุดต่อต้องปรับจากภาพจริง
- textureมีalphaบางบริเวณขอบแสง ตรวจบนฉากขาว/ดำและที่ขนาดโทรศัพท์ก่อนrelease ห้ามใช้color-keyลบดำโดยไม่ดูglow

generation_jobs.jsonคือพรอมต์ต้นทาง; record_01..10.jsonเก็บพรอมต์ที่ใช้จริงและsource path ภาพสร้างด้วยChatGPT built-in imagegen ไม่ตัดชิ้นส่วนจากบอร์ดอ้างอิง

ยังไม่ได้ทดสอบภาพในGodotหรือยืนยันการลงทะเบียนทุกพิกเซล รายงานนี้ระบุคุณสมบัติไฟล์และข้อจำกัดตามจริง
