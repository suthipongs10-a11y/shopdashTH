# ROCKET BREAKERS — BATCH 007

ครบ 6 PNG: ไอคอนอาวุธ 3 แบบ และ glow แยก 3 แบบ ตามชื่อไฟล์ที่ขอ
สร้างทีละภาพด้วยเครื่องมือสร้างภาพในตัว ขนาดจริงทุกภาพ 1254×1254 (คำขอ 512×512; อัตราส่วน 1:1)
เก็บต้นฉบับ ไม่ย่อ ไม่แก้พิกเซล ทุกภาพเป็น RGBA มี alpha จริง ไม่มีพื้นหลังดำทึบหรือ checkerboard วาดติดภาพ

Needle Cannon ส่งรุ่นแก้ลำกล้องเดี่ยว; Pulse Laser แกนฟ้าขาว; Scorpion Tail โค้งหางและแกนพลาสมาม่วง
ไอคอนใช้มุม front-three-quarter ตามคำขอเฉพาะของ batch ไม่ใช่ sprite อาวุธมุม top-down สำหรับติดบนยานโดยตรง
ไฟล์ glow มีเฉพาะแสง ไม่มีตัวอาวุธ และใช้ additive blend ตามคำขอ ต้องทดสอบความสว่าง/alpha กับ renderer จริง

ตรวจพื้นดำ ขาว checkerboard และ thumbnail 32px แล้ว สีและทรงหลักต่างกัน แต่รายละเอียดกลไกจะลดลงที่ขนาดเล็ก ต้องทดสอบ HUD จริง
ไม่พบส่วนชัดเจนถูกตัดขอบที่ alpha>16 ขอบบางภาพมี alpha จางมาก 1–3/255 โดยเฉพาะ glow ควรทดสอบ atlas bleed

ตำแหน่ง glow ที่ขอ normalized=(0.5,0.169921875), บน canvas จริง=(627,213.082)
แกนแสงที่วัดจากบริเวณสว่างขาว:
- W001: (626.09,214.51)
- W008: (628.26,195.25)
- W022: (625.98,196.03)
เป็นการประมาณจากแกนสว่าง ไม่ใช่ anchor ที่ยืนยันในเอนจิน ค่า normalized และ bbox อยู่ใน delivery_manifest.json
ควรใช้แกนแสงที่วัดเป็น pivot แล้ววางที่ muzzle socket ของ sprite อาวุธในโลกเกม ปรับขนาด/offset ต่ออาวุธ
อย่าวาง glow ทับ canvas ไอคอน HUD ตรงๆ: ไอคอนเป็นมุมสามส่วน ปากกระบอกจึงไม่ได้อยู่จุดเดียวกับไฟล์ glow
