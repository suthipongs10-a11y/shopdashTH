# BATCH_002 — Power Up icons

สร้างจาก ZIP ที่ดาวน์โหลดจากลิงก์ GitHub ซึ่งผู้ใช้ส่งมาในรอบนี้ ไม่ใช้ชุดคำขอเก่าแทน ไอคอน12ชนิดแยกเป็นPNGรายภาพ ไม่ใช่ภาพบอร์ดรวมและไม่ใช่การตัดรูปจากภาพอ้างอิง

ชื่อไฟล์ `rb_pickup_pu01_000.png` ถึง `rb_pickup_pu12_000.png` ตรงกับคำขอ: ยิงสามทาง แกนเลเซอร์ ฝูงมิสไซล์ สายฟ้าชิ่ง โล่ ซ่อมยาน แม่เหล็ก หล่อเย็น โอเวอร์ไดรฟ์ โดรนคู่ แกนหลอม และลังเศษโลหะ

ทุกZIPเป็นไฟล์เปิดแยกได้ แตกลงที่เดียวกันเพื่อรวมโฟลเดอร์ RB_BATCH_002_DELIVERY ส่งโฟลเดอร์นี้ให้Claudeเพื่อตรวจและimportเข้าเกม

## ขนาดและการนำเข้า

ขนาดที่ขอคือ512×512 ดูขนาดจริงในdelivery_manifest.json ห้ามถือว่าภาพมีขนาด512จากชื่อไฟล์ เครื่องมือสร้างภาพอาจให้ต้นฉบับใหญ่กว่า จึงเก็บต้นฉบับไว้และให้Claudeย่อในขั้นตอนimportตามขนาดที่เกมใช้

ตรวจช่องalphaและพื้นที่โปร่งใสจริง พร้อมbounding boxของส่วนที่มองเห็นในรายงาน ภาพแสงมีalphaบาง ไม่ควรลบสีดำด้วยcolor-keyจนเสียglow ตรวจบนฉากสว่าง/มืดตอนimport และทำedge cleanupถ้าจำเป็น

สถานะคือgenerated_awaiting_engine_QA ยังไม่ใช่approved/integrated ต้องตรวจความคมที่48px ตำแหน่งpivotกลางภาพ ขนาดบนหน้าจอโทรศัพท์ และวัสดุblendจริงในเกม ความละเอียดสูงไม่ได้รับรองว่าอ่านง่ายเมื่อย่อแล้ว

PU01มี3ลูกตามคำขอ ส่วนPU10เป็นโดรน2ตัวที่รวมเป็นไอคอนหนึ่งชิ้น ไม่ได้ใช้จำนวน4จากบอร์ดอ้างอิง รูปเหล่านี้เป็นpickup icons ไม่ใช่spriteของกระสุนที่ยิงจริง
