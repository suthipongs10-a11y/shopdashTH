# ROCKET BREAKERS — BATCH 006

ครบ 10 ไอคอน PNG ตามชื่อที่ร้องขอ สร้างทีละภาพด้วยเครื่องมือสร้างภาพในตัว โดยใช้ BATCH 005 เป็นภาพอ้างอิงสไตล์

ขนาดจริงทุกภาพ 1254×1254 (คำขอ 512×512 อัตราส่วน 1:1 ตรงกัน) เก็บต้นฉบับ ไม่ย่อหรือแก้ไขพิกเซล
ทุกภาพ RGBA มี alpha จริง 0–255 ตรวจบนพื้นมืด ขาว และตารางแล้ว ไม่พบส่วนที่มองเห็นถูกตัดขอบ
Hangar มี alpha 1 บางจุดที่ขอบ ซึ่งจางมาก ควรตรวจขอบ texture atlas ก่อนปล่อยจริง

ภาพย่อ 32px ตรวจเบื้องต้นแล้ว แต่ยังต้องทดสอบกับเมนูและอุปกรณ์จริง รายละเอียด Blueprint/Scrap/Hangar บางส่วนลดลงเมื่อย่อ
ดาวเต็มกับดาวว่างเป็นคู่สไตล์เดียวกัน แต่ขอบเขตดาวว่างใหญ่กว่าดาวเต็ม ต้องปรับ runtime scale และตำแหน่งตอนสลับสถานะ ไม่ควรใช้ขนาด canvas เท่ากันแล้วคาดว่าดาวจะใหญ่เท่ากัน
ใช้ visible_bbox_alpha_gt16 ใน manifest จัดให้อยู่ในช่องไอคอนเดียวกัน ค่า suggested_fit_32px เสนอให้ด้านยาวของเนื้อภาพอยู่ที่ 24px ในช่อง 32px โดยคงสัดส่วน แล้วปรับทางสายตาในเกม
pivot canvas = (627,627) หรือ normalized (0.5,0.5) ค่า bbox center คือกึ่งกลางเนื้อภาพสำหรับปรับ layout

PART 02: blueprint, hangar, galaxy
PART 03: codex, fusion_core, extraction
