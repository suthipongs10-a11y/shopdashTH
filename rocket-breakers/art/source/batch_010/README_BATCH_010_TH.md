# ROCKET BREAKERS — BATCH 010

ส่งมอบครบ 10 PNG: B01 Rivet Crab และ B03 Furnace Ram ตัวละ core, armor, joint, signature_mount, damage_overlay ตามชื่อในคำขอ (ชุดนี้ไม่มี B02 แม้หัวข้อกล่าว B01–B03)
สร้างทีละภาพด้วยเครื่องมือสร้างภาพในตัว ขนาดจริงทุกภาพ 1254×1254 พิกเซล (คำขอ 1024×1024 อัตราส่วน 1:1 ตรงกัน)
เก็บต้นฉบับ ไม่ย่อหรือแก้พิกเซล ทุกภาพ RGBA alpha จริง 0–255 ตรวจพื้นดำ ขาว และตารางแล้ว ไม่มีพื้นหลังทึบวาดติดภาพ
ไม่พบส่วนชัดเจนถูกตัดขอบที่ alpha>16 บางไฟล์มี alpha จางมาก 1/255 ที่ขอบ ควรตรวจ texture atlas bleed

## การประกอบในเกม
ทุกชิ้นแยกไฟล์ ไม่ได้ฝังก้ามซ้ายหรือหัวกระแทกที่ขโมยได้ไว้กับ core
ภาพใช้มุมบนตามคำขอ แต่รายละเอียดทรงสูงและ socket มี perspective เล็กน้อย ต้องตรวจความเข้ากันตอนประกอบ
ชิ้นส่วนยังไม่ผ่านการประกอบและทดสอบในเอนจิน ไม่ควรอ้างว่า pivot/สเกลตรงกันทุกพิกเซล
ส่วนที่หลุดได้อยู่ในตระกูลวัสดุ/ดีไซน์เดียวกัน แต่ไม่ใช่การตัด geometry จากภาพบอสที่ประกอบสำเร็จ
ใช้ assembly_guide.json เป็นจุดเริ่มต้นตั้ง socket (ค่าโดยประมาณจากภาพ ต้องยืนยันด้วยตาใน editor)
ปรับขนาด joint ให้เท่าช่องยึดบน core แล้วปรับ coupling ของชิ้นส่วนให้ขนาดเข้ากัน ตั้ง pivot ที่ socket ของแต่ละชิ้น เกราะมี canvas แยกและต้องย่อให้ปิดข้อต่อพอดี
อย่าวางภาพทุกไฟล์ที่ origin และขนาดเท่ากันโดยตรง
pivot กลาง canvas จริง=(627,627) ส่วน socket ปลายชิ้นส่วนที่สั่ง (512,870) บน 1024 จะเทียบเป็น (627,1065.41) บนไฟล์จริง แต่ภาพที่ได้มีตำแหน่งคลาดเคลื่อน ค่า estimate แนบแยกแล้ว

## รอยเสียหาย
เป็นชั้นโปร่งใสเฉพาะรอยไหม้ รอยแตก สายไฟและประกาย ไม่ใช่ภาพบอสเต็มซ้ำ
ใช้ canvas เดียวกับ core; B01 รอยที่เห็นกินพื้นที่ 9.14% ของ canvas, B03 7.25%
ตรวจด้วย alpha>16: B01 มีพิกเซลรอย/ประกายเกิน silhouette ลำตัวประมาณ 2.61% ของพิกเซลรอยที่เห็น; B03 ไม่พบส่วนเกินที่ threshold นี้
ใช้ alpha ของ core เป็น mask และตัดช่อง socket ออกจากรอย ตรวจ plate registration จริงอีกครั้งก่อนปล่อยเกม ตัวเลขนี้ไม่ใช่การรับรองความตรงทุกพิกเซล
