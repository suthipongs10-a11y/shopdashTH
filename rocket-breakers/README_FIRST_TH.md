## ส่งให้ Claude

ส่ง ZIP01+02 ก่อนเพื่อให้เริ่มระบบได้ แล้วส่ง03–06เป็นภาพอ้างอิง หรือแตกครบแล้วส่งทั้งโฟลเดอร์ อ่าน `CLAUDE_START.md` แล้วคัดลอกข้อความเริ่มงานให้ Claude หากแนบได้จำกัด ให้เริ่มจาก01และ02 ไม่ต้องรอภาพทั้งหมดเพื่อเริ่มเขียนเกม

หลังสร้างโครงเกม ให้ Claude ทำ M1 ด่านทดลองที่ขโมยหางแมงป่องมาติดยานได้จริงก่อน แล้วตรวจความสนุกและการควบคุม ค่อยขยายตามแผน M2–M6 เมื่อ Claude ต้องการภาพ ให้ส่งไฟล์ `art/requests/BATCH_###.md` และภาพอ้างอิงกลับมาให้ ChatGPT สร้าง ไม่มีการอ้างว่าโปรแกรมสองตัวส่งภาพถึงกันอัตโนมัติ

## สถานะงาน

เอกสารนี้เป็น **ข้อกำหนดออกแบบและแพ็กส่งต่อพัฒนา** ไม่ใช่เกมที่สร้างเสร็จ ภาพ4ภาพเป็น concept board ที่มีบางภาพรวมหลายตัว/เอฟเฟกต์ ยังไม่ใช่ sprite/แอนิเมชันพร้อมนำเข้าเกม ค่าHP ดาเมจ ราคาและจำนวนศัตรูเป็นค่าเริ่มต้นที่ต้องปรับจาก playtest

รายการ asset แยกสถานะ planned กับ generated_unchecked ชัดเจน ภาพ production ต้องผ่านการตรวจalpha ขนาด anchor และตำแหน่งข้อต่อก่อนใช้ สร้างภาพและเอฟเฟกต์เป็นแบตช์เล็กเพื่อคุมความต่อเนื่อง ส่วนเสียงจริงต้องมีขั้นตอนสร้าง/จัดหาเสียงแยกจากเครื่องมือสร้างภาพ

## ตรวจแพ็ก

เมื่อรวมไฟล์ครบ ใช้ Python3รัน `python tools/validate_bundle.py` จากโฟลเดอร์นี้ เพื่อตรวจจำนวนID, ความเชื่อมโยงบอสกับอาวุธ, จำนวนดาว, loadoutเริ่มต้น, รายการภาพ และchecksumภาพ ไม่ใช่การทดสอบเกมที่ยังไม่ได้เขียน

ภาษาหลักของเอกสารอธิบายมีทั้งไทยและอังกฤษเพื่อให้ coding agentใช้คำเทคนิคได้แม่น ตัวเกมต้องรองรับไทยและอังกฤษตั้งแต่เริ่ม ห้ามนำข้อความเทคนิคจากเอกสารไปใส่ในหน้าจอผู้เล่นโดยไม่ปรับให้อ่านง่าย
