# ชุดเสริม 1.1 — เอฟเฟกต์ Power Up และฝูงศัตรู

นำชุดนี้รวมกับแพ็ก01–06ก่อนหน้า โดยแตกZIPลงตำแหน่งเดียวกัน จะเพิ่มโฟลเดอร์ `ROCKET_BREAKERS_HANDOFF/expansion_01` ไม่มีการแทนที่เอกสารเดิม

ให้ Claude อ่าน `POWERUPS_AND_SPECTACLE.md` เพิ่มหลังสเปกเดิม แล้วอ่าน `data/powerups.json` เพื่อทำระบบPower Upเก็บระหว่างเล่น12ชนิด ค่านี้เป็นแบบออกแบบเริ่มต้น ยังไม่ได้ทดสอบในเกมจริง

## ภาพชุดใหม่8ภาพ

- เอฟเฟกต์แยก4ภาพ: ระเบิด สายฟ้าไอออน โล่รับการโจมตี และกระสุนพลาสมา เป็นภาพต้นทางเดี่ยว มีรายงานตรวจalpha ไม่ใช่แอนิเมชันหลายเฟรม
- ภาพอ้างอิง4ภาพ: Power Up12แบบ ศัตรู12บทบาท บอส6ตัวพร้อมชิ้นส่วนที่ขโมยได้ และฉากเล่นที่เปิดใช้อาวุธ/Power Upหลายชนิด

ภาพศัตรู/บอสเป็นการแสดงตัวอย่างจากรายการเดิม ไม่ใช่จำนวนตัวใหม่เพิ่มซ้ำ รายการเดิมมีศัตรูทั่วไป24ชนิดและบอส/มินิบอส16ตัว ส่วนภาพอาวุธ เอฟเฟกต์ และตัวละครทั้งหมดของเกมยังต้องผลิตต่อ

## นำไปใช้

1. ส่งไฟล์เอกสารของชุดเสริมให้Claudeก่อน เพื่อยืนยันว่าเกมต้องยิงมันและมีPower Up ไม่ได้เน้นเล็งข้อต่อเพียงอย่างเดียว
2. ส่งPNGแยก4เอฟเฟกต์ให้ใช้ทดสอบparticles/trails/material โดยตรวจคุณภาพจริงและปรับขนาดก่อน สถานะยังเป็นsource candidate ไม่ใช่approved final
3. ใช้ภาพboardเพื่อให้ChatGPTสร้างไอคอน/ยาน/ชิ้นส่วนแยกต่อ ห้ามนับภาพรวมboardว่าเป็นspriteครบแล้ว
4. เอฟเฟกต์การเคลื่อนไหวต้องประกอบจากภาพต้นทางร่วมกับโค้ด particles เวลา แสง และเสียง ภาพเดียวไม่ได้ทำให้ระเบิดเคลื่อนไหวสำเร็จ

ดู `art_manifest.json` สำหรับสถานะ ที่มาภาพ ขนาด และalpha; ดู `art_generation_prompts.json` สำหรับคำสั่งสร้างภาพแต่ละภาพ ส่วน `IMAGE_QA.json` ระบุผลตรวจไฟล์จริง

## ZIP ชุดเสริม

- 07_POWERUP_RULES: เอกสารเพิ่มระบบPower Up12ชนิด สูตรประกอบเอฟเฟกต์18แบบ ข้อมูลJSON คำสั่งสร้างภาพ และรายงานตรวจไฟล์
- 08_VFX_FIRE_ION: PNGโปร่งใสระเบิดและสายฟ้า
- 09_VFX_SHIELD_PLASMA: PNGโปร่งใสโล่และพลาสมา
- 10_POWERUPS_ENEMIES: ภาพPower Up12แบบและศัตรู12บทบาท
- 11_BOSS_SALVAGE: ภาพบอส6ตัวพร้อมอาวุธที่ขโมยได้
- 12_GAMEPLAY_POWERUP: ภาพฉากเล่นที่มีPower Up อาวุธและศัตรูหลายชนิด

ทุกชุดเป็นZIPเปิดแยกได้ ไม่ใช่ไฟล์แบ่งนามสกุลz01 และจะรวมลงโฟลเดอร์expansion_01เดียวกันภายใต้โปรเจกต์เดิม
