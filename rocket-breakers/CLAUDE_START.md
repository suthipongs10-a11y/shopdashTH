# ข้อความเริ่มงานสำหรับ Claude

คัดลอกข้อความด้านล่างไปพร้อมไฟล์ ZIP ทั้งชุด หรือแตกไฟล์ไว้ที่รากโปรเจกต์แล้วให้ Claude อ่าน:

> สร้างเกม ROCKET BREAKERS ตาม AGENTS.md และเอกสารทั้งหมดในแพ็กนี้ ให้เริ่มจาก M0 แล้วทำ M1 ให้เล่นได้จริงก่อนขยายเกม ผมต้องการเกมยิงยาน 2.5D ที่ยิงข้อต่อบอสให้ชิ้นส่วนหลุด ลากเก็บ แล้วนำอาวุธหรือความสามารถมาติดยานของเรา ทำให้บอสเสียความสามารถนั้นจริง คุณรับผิดชอบโค้ด ระบบ ฟิสิกส์ shader particles การรวมไฟล์ภาพ เสียงต้นแบบ build และทดสอบ ส่วน ChatGPT เป็นผู้สร้างภาพ raster และภาพเอฟเฟกต์ขั้นสุดท้ายทั้งหมด ให้คุณจัดคำขอภาพเป็น BATCH ตาม ART_BIBLE พร้อมชื่อไฟล์ ขนาด anchor และภาพอ้างอิง เพื่อให้ผมนำกลับไปสั่ง ChatGPT อย่าอ้างว่าเชื่อมไปสร้างภาพเองถ้าไม่มีระบบจริง ใช้ placeholder ที่ระบุสถานะได้ระหว่างพัฒนา อ่าน data/catalog.json และตรวจจำนวนรายการก่อนเริ่ม ห้ามตัดเกมเหลือแค่ภาพ mockup หรือเปลี่ยนเป็น pixel art ส่งผลลัพธ์เป็นโปรเจกต์ที่รันได้ พร้อมวิธีรัน ผลทดสอบ และรายการงานต่อ ไม่ต้องรอภาพครบจึงเริ่มสร้างระบบหลัก

## ลำดับอ่าน

1. AGENTS.md — ภาพรวมและกฎการทำงาน
2. docs/SYSTEMS.md — สูตรและขอบเขตระบบ
3. data/catalog.json และ docs/CONTENT_CATALOG.md — รายการเกมทั้งหมด
4. docs/TECHNICAL.md — สัญญาข้อมูล สถาปัตยกรรม การบันทึก และทดสอบ
5. docs/ART_BIBLE.md + art/concepts — ภาพและสเปก asset
6. docs/PRODUCTION.md + art/requests/BATCH_001.md — เริ่มทำงานเป็นช่วง

## ไฟล์นี้มีอะไรแล้ว / ยังไม่มีอะไร

มีเอกสารออกแบบครบขอบเขต v1 แค็ตตาล็อกข้อมูล ค่าเริ่มต้น ระบบดาว/รางวัล รายการ asset แผนทดสอบ และภาพคอนเซปต์4ภาพ ยังไม่มีเกมที่คอมไพล์แล้ว ไม่มี sprite production ที่ตรวจ alpha/anchor แล้ว และไม่มีเสียงสำเร็จรูป ตัวเลขต้องปรับจากการเล่นจริง

ใช้ AGENTS.md ตัวพิมพ์ใหญ่ตามชื่อมาตรฐานเพื่อให้ agent ค้นพบง่าย หากเครื่องมือของคุณอ่าน CLAUDE.md ให้สร้างไฟล์สั้นที่บอกให้อ่าน AGENTS.md และเอกสารอ้างอิง ห้ามทำสำเนาสเปกสองชุดที่แก้ไม่พร้อมกัน
