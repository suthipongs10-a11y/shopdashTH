# แท็กซี่อุบล.com — เว็บไซต์ใหม่ (Static, Cloudflare Pages)

โปรเจ็คนี้แยกจาก ShopDash โดยสมบูรณ์ ไม่มี dependency (ใช้แค่ Node 18+) สร้าง HTML ล้วนเพื่อให้โหลดเร็วที่สุด
แต่ละหน้าไม่มี JavaScript, ใช้ CSS ไฟล์เดียว (~10 KB) ที่ cache ได้ 1 ปี ฟอนต์ Kanit (หัวข้อ) + Anuphan (เนื้อหา) โฮสต์เองใน `static/fonts` (โหลดเฉพาะชุดอักษรไทย+ละติน ~87 KB, cache 1 ปี, ลิขสิทธิ์ OFL)

```
taxi-ubon/
  site.config.mjs      ← เบอร์โทร, LINE, ที่อยู่, โดเมน (แก้ที่นี่ที่เดียว)
  content/pages.mjs    ← เนื้อหาทุกหน้า (เพิ่มหน้าใหม่ = เพิ่ม object)
  build.mjs            ← ตัว generate → dist/
  static/              ← CSS, favicon, og.png, _headers, _redirects
  scripts/serve.mjs    ← preview ในเครื่อง: node scripts/serve.mjs → http://localhost:8788
  scripts/make-images.mjs ← สร้าง og.png / apple-touch-icon.png ใหม่ (ต้องมี playwright)
  photos-src/          ← รูปต้นฉบับ
  static/img/          ← รูป WebP ที่ย่อแล้ว 480/800/1200px (สร้างโดย scripts/optimize-images.mjs)
  content/images.json  ← ขนาดรูป (สร้างอัตโนมัติ ใช้ตอน build)
```

### เพิ่ม/เปลี่ยนรูป
1. วางไฟล์ .jpg ใน `photos-src/` (ตั้งชื่อภาษาอังกฤษ เช่น `airport-pickup.jpg`)
2. `npm i --no-save sharp && node scripts/optimize-images.mjs` → ได้ WebP หลายขนาด (ลบ EXIF/GPS ออกให้แล้ว)
3. เพิ่มคำอธิบายรูป (alt) ใน `photos` ใน `build.mjs` แล้วใส่ `image: 'airport-pickup'` ในหน้าที่ต้องการใน `content/pages.mjs`
   (ถ้าไม่ใส่ จะใช้รูปตามกลุ่มหน้าจาก `groupPhoto`)

## Deploy บน Cloudflare Pages

1. Cloudflare Dashboard → Workers & Pages → Create → Pages → Connect to Git → เลือก repo นี้
2. Settings:
   - **Root directory:** `taxi-ubon`
   - **Build command:** `node build.mjs`
   - **Build output directory:** `dist`
   - Environment variable `NODE_VERSION` = `20`
3. Custom domains → เพิ่ม `แท็กซี่อุบล.com` (ใช้ punycode `xn--12cu8ao9c4b1cza9ezco.com`)
   และ `www.` → ตั้ง Redirect Rule `www` → non-www แบบ 301 (canonical ของเว็บเดิมเป็น non-www)
4. หลังชี้ DNS แล้ว: Google Search Console → ส่ง `https://xn--12cu8ao9c4b1cza9ezco.com/sitemap.xml`
   และกด "ตรวจสอบ URL" หน้าเดิมทั้ง 7 หน้าเพื่อให้ Google crawl ใหม่

## เพิ่มหน้าใหม่
เพิ่ม object ใน `content/pages.mjs` (หรือเรียก `province({...})` / `district({...})` สำหรับหน้าเส้นทาง)
