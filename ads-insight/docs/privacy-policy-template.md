# นโยบายความเป็นส่วนตัว — Ads Insight

**อัปเดตล่าสุด:** [วันที่]

## แอปนี้คืออะไร

Ads Insight เป็นเครื่องมือภายในที่ [ชื่อคุณ / ชื่อกิจการ] สร้างขึ้นเพื่อใช้จัดการและวิเคราะห์
**บัญชีโฆษณา Google Ads ของตัวเอง** ไม่ได้เปิดให้บุคคลทั่วไปสมัครหรือใช้งาน

## ข้อมูลที่เข้าถึง

เมื่อคุณอนุญาตผ่านหน้าจอยินยอมของ Google แอปจะเข้าถึง:

- **ข้อมูลบัญชี Google Ads** ผ่าน Google Ads API — แคมเปญ คีย์เวิร์ด คำค้น ข้อความโฆษณา
  งบประมาณ และตัวชี้วัดผลงาน (scope `https://www.googleapis.com/auth/adwords`)
- **อีเมลของบัญชี Google** ที่ใช้ล็อกอิน เพื่อยืนยันว่าเป็นเจ้าของที่ได้รับอนุญาต
  (scope `userinfo.email`)

แอปไม่เข้าถึงอีเมล ไฟล์ ปฏิทิน รายชื่อผู้ติดต่อ หรือข้อมูลอื่นใดในบัญชี Google ของคุณ

## การเก็บและใช้ข้อมูล

- ข้อมูลถูกใช้เพื่อ **แสดงรายงาน วิเคราะห์ผล และดำเนินการแก้ไขแคมเปญตามที่ผู้ใช้อนุมัติ** เท่านั้น
- ข้อมูลเก็บบน Cloudflare Workers และฐานข้อมูล Cloudflare D1
- **Refresh token เก็บแบบเข้ารหัส (AES-GCM)** ไม่เคยถูกบันทึกลง log หรือแสดงผลเต็มรูปแบบ
- ไม่มีการขาย ให้เช่า หรือโอนข้อมูลให้บุคคลที่สามเพื่อการโฆษณาหรือการตลาด

## การประมวลผลด้วย AI

ข้อมูลผลงานโฆษณาบางส่วนถูกส่งไปยัง **Anthropic (Claude)** เพื่อวิเคราะห์และให้ข้อเสนอแนะ
ตามคำสั่งของผู้ใช้ ข้อมูลที่ส่งจำกัดเฉพาะเท่าที่จำเป็นต่อการวิเคราะห์ในครั้งนั้น
การเปลี่ยนแปลงใดๆ ที่มีผลกับบัญชีโฆษณาจริง **ต้องผ่านการอนุมัติจากผู้ใช้ทุกครั้ง**
ระบบไม่แก้ไขบัญชีโดยอัตโนมัติ

## การใช้งานแบบจำกัด (Limited Use)

> การใช้และการถ่ายโอนข้อมูลที่ได้รับจาก Google API ไปยังแอปพลิเคชันอื่นของ Ads Insight
> เป็นไปตาม [นโยบายข้อมูลผู้ใช้บริการ Google API](https://developers.google.com/terms/api-services-user-data-policy)
> รวมถึงข้อกำหนดการใช้งานแบบจำกัด (Limited Use requirements)

*Ads Insight's use and transfer of information received from Google APIs to any other app
will adhere to the [Google API Services User Data Policy](https://developers.google.com/terms/api-services-user-data-policy),
including the Limited Use requirements.*

## การเก็บรักษาและการลบข้อมูล

คุณเพิกถอนสิทธิ์ได้ตลอดเวลาที่ https://myaccount.google.com/permissions
เมื่อเพิกถอนแล้ว แอปจะเข้าถึงบัญชี Google Ads ของคุณไม่ได้อีก
หากต้องการให้ลบข้อมูลที่เก็บไว้ทั้งหมด ติดต่อตามช่องทางด้านล่าง
